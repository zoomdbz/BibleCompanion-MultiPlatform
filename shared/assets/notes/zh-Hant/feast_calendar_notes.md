# 聖經節期與兩種古代曆法

神在利未記23章中命定了七個節期，每一個都與以色列的農業週期相關聯，每一個都預指彌賽亞的工作。這些不是可選的傳統；它們是「指定的時間」（希伯來語：*moadim*），是神的曆法上所設定的神聖約會（利未記23:2）。

## 第二聖殿時期的兩種曆法

到耶穌的時代，猶太民中通行著兩種曆法系統：

### 希伯來陰陽曆
這是聖殿祭司體系和主流猶太教從古至今所使用的曆法。它以月亮計算月份（新月 = 新的一月），並在十九年中加入七個閏月（默冬週期），以保持與太陽季節的一致。月份的天數在29天和30天之間交替。由於必須目視確認新月，月份的確切開始可能有一天的不確定性，這就是為什麼吹角節（提斯利月1日）傳統上要守兩天，也是為什麼**「那日子，那時辰，沒有人知道」**（馬太福音24:36）是這個節期的一個廣為人知的慣用語。第一世紀的猶太聽眾會立刻辨認出來，就如同中文裡「八九不離十」這樣的俗語一般自然。

### 艾賽尼太陽曆（364天）
在死海古卷中發現（特別是《禧年書》和《以諾一書》），這種曆法恰好計算364天，即52個完整的星期。每個節期每年都落在一週中的同一天。一年從星期三開始（創造的第四天，光體被造之時，創世記1:14-19）。安妮·喬貝爾等學者提出，耶穌在最後的逾越節遵循了這種曆法，這將把最後的晚餐定在週二晚上，解決了福音書之間的表面矛盾：對觀福音（說耶穌吃了逾越節的筵席）與約翰福音（說釘十字架發生在聖殿逾越節之前）。如果耶穌使用了艾賽尼曆法而聖殿使用了陰陽曆法，那麼兩種記載都是準確的：耶穌在艾賽尼曆尼散月14日（週二）守逾越節，而聖殿的逾越節則在陰陽曆尼散月14日（週五）。

## 七個節期

### 春季節期: 在第一次降臨中已應驗
- **逾越節**（尼散月14日）: 羔羊被殺。耶穌在逾越節被釘十字架（哥林多前書5:7；約翰福音19:14）。
- **除酵節**（尼散月15-21日）: 酵（罪）被除去。耶穌無罪且被埋葬（彼得前書2:22；哥林多前書5:8）。
- **初熟節**（尼散月16日）: 初熟的莊稼捆在耶和華面前搖一搖。耶穌從死裡復活，成為「睡了之人初熟的果子」（哥林多前書15:20）。
- **五旬節 / 七七節**（西彎月6日）: 初熟節後五十天。聖靈在這一天澆灌下來（使徒行傳2:1-4）。律法也在同一日期在西奈山頒佈（出埃及記19:1）。

### 秋季節期: 等候在第二次降臨中應驗
- **吹角節 / 約姆·特魯阿**（提斯利月1日）: 號角吹響。預指基督的再來：「因為主必親自從天降臨，有呼叫的聲音和天使長的聲音，又有神的號吹響」（帖撒羅尼迦前書4:16）。這就是「那日子、那時辰沒有人知道」的那個節期。
- **贖罪日 / 約姆·基普爾**（提斯利月10日）: 大祭司進入至聖所。預指以色列全國的悔改和最終的贖罪：「以色列全家都要得救」（羅馬書11:26-27；撒迦利亞書12:10）。
- **住棚節 / 蘇克棚**（提斯利月15-21日）: 神與祂的百姓同住在棚中。預指彌賽亞的國度：「看哪，神的帳幕在人間。祂要與人同住」（啟示錄21:3；撒迦利亞書14:16-19）。

## 其他被命令的遵守

並非每一次神聖約定都能放入月曆格中。妥拉還命令了四項遵守，但它們要麼太頻繁，要麼太稀少，要麼以年而非日來計量時間：

- **每週安息日**（利未記 23:3）：在年度節期之前最先列出的定時；每週從星期五日落到星期六日落守之。
- **新月 / 月朔**（民數記 10:10; 28:11–15）：每月起始的獻祭與吹角；標示神對時間本身的主權。
- **安息年 / 施米塔**（利未記 25:1–7）：每第七年土地安息；不耕種、不修剪，債務得免（申命記 15:1–2）。
- **禧年 / 約貝爾**（利未記 25:8–12）：經過七個安息年的循環後，在第五十年吹響羊角宣告；奴僕得釋放，祖業歸還原家。此模式預指基督，主在路加福音 4:18–19 宣告「主悅納人的禧年」（引以賽亞 61:1–2）。

這些超出每月格子的範圍，但仍是完整聖經曆法的一部分。

## 創世記1:14

「神說：『天上要有光體，可以分晝夜，作**記號**，定**節令**（*moadim*，即指定的時間），日子，年歲。』」天體的創造，部分目的就是標記神的節期曆法。
