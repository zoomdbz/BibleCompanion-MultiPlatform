# **FAQs：關於上帝、信仰與現實的深度問題**

---

### **1. 為什麼上帝不以公開且可聽見的方式顯明自己？**

在聖經中，上帝常常隱藏自己，為要被人尋找；並非因祂缺席，而是因為關係需要人的追求。

在 **出埃及記 33:20**，上帝對摩西說：「人見我的面不能存活。」

這不是懲罰的問題；而是無限與有限相遇的問題。直接暴露在如此浩大的榮耀之下會壓垮人的意識。  
**經文支持：**

- **提摩太前書 6:16** : 「那獨一不死、住在人不能靠近的光裡、是人未曾看見也是不能看見的。」

- **出埃及記 19:16–18** : 當上帝降臨西奈山時，「遍山大大的震動」；百姓遠遠站立，難以承受祂的同在。

- **以賽亞書 6:5** : 以賽亞看見主的榮光便喊說：「禍哉！我滅亡了……因為我親眼見到大君王；萬軍之耶和華。」

- **以西結書 1:28** : 以西結看見「耶和華榮耀的樣式的形像」，就俯伏在地。  
  這些經文表明，神聖的臨在會淹沒人的感官；不是因怒氣，而是因其本身的強烈與聖潔。

然而，上帝有時以可感的方式顯現；燃燒的荊棘（**出埃及記 3**）、火柱雲柱（**出埃及記 13:21**）、以利亞所聽見的微小聲音（**列王紀上 19:11–13**），以及最完全的啟示在 **耶穌** 裡，祂被稱為「那不能看見之神的像」（**歌羅西書 1:15**）。  
規律是明確的：上帝顯明自己到足以邀請人信靠；卻不至於消除人的自由意志。若祂向眾人以無法否認的方式顯現，信仰就會變成被迫，而非選擇。

### **2. 既然上帝全知且完全良善，為什麼要設立一條祂知道亞當和夏娃會違反的規矩？**

乍看之下，伊甸園的命令似乎不公平；為何設立一條人類最終會破壞的律？  
但聖經表明，伊甸並非陷阱；而是道德自由的課堂。  
愛、信任與順服只在有真實可能不去愛、不去信、不去順服的情況下才能存在。

上帝本可以創造「被編程」的受造物，從不犯罪；他們也許高效，卻無法去愛。  
那「分別善惡樹」與其說是誘惑，不如說是一道界限；一個可見的提醒，表明受造界是依賴的，而非自主的。  
逾越它，就是選擇自我定義而非與神相交。  
這場悲劇被預知，卻非被強迫；預知不是因果。

**經文支持：**

- **創世記 2:16–17** : 「園中各樣樹上的果子，你可以隨意喫；只是分別善惡樹上的果子，你不可喫，因為你喫的日子必定死。」

- **申命記 30:19–20** : 「我將生與死、福與禍擺在你面前；所以你要揀選生命。」  
  上帝的性情是一致的；祂看重選擇，因為選擇奠定了愛的基礎。

- **羅馬書 5:12** : 「這就如罪是從一人入了世界，死又是從罪來的；於是死就臨到眾人，因為眾人都犯了罪。」  
  墮落帶來的是後果；不是任意的刑罰。

- **羅馬書 5:18–19** : 「因一次的過犯，眾人都被定罪；照樣，因一次的義行，眾人也都被稱義得生命。」  
  墮落使救贖成為必須，也使之成為可能。

- **哥林多前書 15:22** : 「在亞當裡眾人都死了；照樣，在基督裡眾人也都要復活。」

伊甸的故事並非關於神的殘酷；而是關於與神的合作。  
上帝允許自由，使愛得以真實；隨後祂親自承擔這自由的代價。  
預知反而預先顯明瞭憐憫；「羔羊是從創世以來被殺的」（**啟示錄 13:8**）。

伊甸的命令從不是陷阱；而是人類覺醒與救贖長路上的第一步。

### **3. 全能的上帝為什麼允許苦難與邪惡存在？**

上帝不是邪惡的創造者。聖經明確說：「上帝不能被惡試探，他也不試探任何人」（**雅各書 1:13**）。他所創造的，他宣告為「甚好」（**創世記 1:31**）；我們今天所看到的是一個因濫用自由意志而敗壞的世界：先是天軍，然後是伊甸園。我們周圍的破碎是叛逆的結果，不是神的設計。真正的問題不是上帝是否創造了邪惡，而是他為什麼允許它存在；答案直指愛的本質。

這是人類歷史上最艱難的問題之一；若上帝慈愛且全能，為何世上有痛苦、不公與悲劇？  
聖經表明，苦難不是神缺席的證據；而是真實自由在有機世界中的代價。

邪惡存在，因為愛需要自由。  
若上帝阻止每一個惡行，選擇的可能性也會被取消；一個沒有自由意志的世界或許有序，卻無愛。  
上帝的能力不是藉著控制一切來證明；而是藉著救贖萬有來彰顯。

苦難顯露受造界的破碎；同時也成為熔爐，煉成信心、憐憫與堅忍。  
連無罪的耶穌也自願進入苦難，為要從裡面救贖它。  
藉著受苦，上帝證明祂不遠離人類的疼痛；祂與我們一同擔當，並將之轉化成超越苦難之物。

**經文支持：**

- **雅各書 1:13**：「上帝不能被惡試探，他也不試探任何人。」  
  上帝不是邪惡的源頭；他與邪惡完全分離。

- **創世記 1:31**：「上帝看著一切所造的都甚好。」  
  創造並非設計上有缺陷；敗壞是因濫用自由意志而入的。

- **創世記 50:20** : 約瑟說：「你們的意念是要害我；但神的意思原是好的，要保全許多人的性命。」  
  上帝不製造惡；祂把惡轉向救贖的目的。

- **羅馬書 8:28** : 「萬事都互相效力，叫愛神的人得益處，就是按祂旨意被召的人。」  
  苦難成為神旨意展開的渠道。

- **雅各書 1:2–4** : 「你們落在百般試煉中，都要以為大喜樂；因為知道你們的信心經過試驗就生忍耐。」  
  痛苦並非無意義；它生出屬靈的成熟。

- **彼得前書 4:12–13** : 「有火煉的試驗臨到你們……倒要歡喜，因為你們是與基督一同受苦。」  
  受苦使信徒與基督的心相契；煉淨憐憫與信心。

- **哥林多後書 4:17–18** : 「我們這至暫至輕的苦楚，要為我們成就極重無比、永遠的榮耀。」  
  痛苦是短暫的；它塑造的榮耀卻是永恆的。

邪惡與苦難顯明墮落世界中自由的後果；也顯明一位不肯置身事外的上帝。  
祂進入自己的創造，成為「多受痛苦、常經憂患的人」（**以賽亞書 53:3**），擔當人類的痛，使之不再擁有最後的話語權。

十字架證明，上帝對苦難的回應不是離棄；而是參與。  
祂不是靠抹去自由來消滅邪惡；乃是以愛轉化其結局而勝過它。  
最終，每一件不義、每一道創傷都將得著答案；「神要擦去他們一切的眼淚」（**啟示錄 21:4**）。  
苦難不會永遠存留；但它所產生的力量將長存。

### **4. 為什麼壞事會臨到好人？**

**《約伯記》**透過一次真實的信心試煉作出回答。乍看之下，這卷書令人道德上不安：上帝似乎允許撒但加害約伯，彷彿在打賭。但那並非虛榮的賭約；而是**法律性與宇宙性的挑戰**。  
天上的問題不是「上帝能否贏一場遊戲」；而是「人在沒有回報時，公義是否仍然存在」。  
撒但指控人類只在順利時才忠誠，暗示一切善行皆出於私利。上帝允許試煉，為要證明真正的信心即使在苦難中也能存留。

約伯的試煉不是刑罰；而是託付。上帝揀選他，因祂知道他的心。苦難揭示動機，也深化關係。約伯在痛苦中呼喊、自辯、求問；上帝並不責難他與真理摔角；反在末了顯現，不是解釋苦難機制，而是重塑他的眼界。約伯遇見上帝的同在後，明白神的智慧超乎人所能測度；當他從強求掌控轉向信靠降服，復興就開始了。約伯的苦難使他與神有了第一手的相遇。

**經文支持：**

- **約伯記 1:8–12** : 神稱約伯「完全正直」，並許可撒但試探他；目的不是毀滅，而是顯明真相。

- **約伯記 2:3–6** : 神再次肯定約伯的正直；試煉為著申張，不是懲治。

- **約伯記 23:10** : 「祂試煉我之後，我必如精金。」

- **約伯記 38–41** : 神的回答指向受造界的奧祕；課題是「眼光」，不是「權能」。

- **約伯記 42:5–6** : 「我從前風聞有你；現在親眼看見你。」從知識進入相遇。

約伯悔改並被更新後，神在眾人面前為他伸冤。祂責備約伯朋友的膚淺神學，說他們「沒有如我的僕人約伯所說的是」（**約伯記 42:7**）。神命令他們獻祭；約伯為他們祈禱，這是寬恕與恩典的舉動。

隨之而來的，是復還。

- **約伯記 42:10** : 「約伯為他的朋友祈禱，耶和華就使約伯從苦境轉回；並且耶和華賜給他的，比他從前所有的加倍。」

- **約伯記 42:12–17** : 約伯得著加倍的產業、新的家庭與長壽安息；晚年平靜。

這段歷史表明：即便沒有回報，信心仍是信心；它駁斥「善行必然帶來即時福報」的交易神學。約伯的痛證實，敬拜不繫於舒適；而繫於真理。  
苦難是暫時的；復興是確定的。

**更多經文：**

- **羅馬書 8:18** : 「現在的苦楚，若比起將來要顯於我們的榮耀，就不足介意了。」

- **雅各書 5:11** : 「你們聽見過約伯的忍耐，也知道主給他的結局；主是滿心憐憫，大有慈悲。」

上帝的公義從未缺席；祂一直在展開。義人或暫時受苦；但信心終要進入申冤與復還。

### **5. 當人向上帝呼求幫助時，為什麼上帝似乎沉默？（以及為何有的禱告蒙應允，有的卻沒有？）**

這沉默不是缺席；而是邀約。祂常藉著忍耐、轉化與黑暗中仍不放棄的愛說得最清楚。  
禱告不是向神通報消息；而是使人心與神旨意對齊。當祂似乎沉默時，祂往往在煉淨人的耐心與信心。神的沉默從非冷漠；而是操練。

- **詩篇 13:1–2** : 「耶和華啊，你忘記我要到幾時呢？」大衛的呼喊表明，沉默是信仰旅程的一部分。

- **以賽亞書 55:8–9** : 「我的意念非同你們的意念；我的道路非同你們的道路。」

- **馬太福音 7:7–8** : 「你們祈求，就給你們；尋找，就尋見；叩門，就給你們開門。」  
  堅持是信靠的憑據。

聖經也給出禱告被延遲、改變或拒絕的若干原因：

**1）與上帝旨意的對齊**

- **約翰一書 5:14–15** : 「若照祂的旨意求……就知道我們所求於祂的無不得著。」

- **路加福音 22:42** : 「然而不要成就我的意思；只要成就禰的意思。」

- **約翰福音 15:7** : 「你們若常在我裡面……凡你們所願意的，祈求就給你們成就。」

**2）上帝的時間與目的**

- **哈巴谷書 2:3** : 「雖然遲延，還要等候；因為必然臨到，不再遲延。」

- **約翰福音 11:4–6** : 耶穌為「神的榮耀」而有意延遲，隨後叫拉撒路復活。

- **但以理書 10:12–13** : 但以理的禱告當時即被垂聽；然而因屬靈爭戰而延緩顯明。

**3）心態與動機**

- **雅各書 4:3** : 「你們求也得不著，是因為你們妄求，要浪費在你們的宴樂中。」

- **詩篇 66:18** : 「我若心裡注重罪孽，主必不聽。」

- **箴言 28:9** : 「轉耳不聽律法的，他的祈禱也為可憎。」

- **彼得前書 3:7** : 丈夫若不體貼同住，「便叫你們的禱告受阻隔。」

**4）在未獲應允時，恩典的夠用**

- **哥林多後書 12:7–9** : 保羅三次求除去「刺」；神說：「我的恩典夠你用；因為我的能力是在人的軟弱上顯得完全。」

**5）聖靈在禱告中的幫助**

- **羅馬書 8:26–28** : 「聖靈幫助我們的軟弱……萬事都互相效力，叫愛神的人得益處。」

**聖經總結：** 神的百姓有時必須等候；神必垂聽；回應與祂的旨意、時間與目的相合；動機與順服相關；當所求未照原樣成就時，恩典仍然支撐；即便無言，聖靈也為我們代求。

### **6. 上帝為何允許無辜的孩子死亡？**

死亡從不是上帝設計的一部分。他造人是為了生命，不是為了墳墓。當他警告亞當「你喫的日子必定死」（**創世記 2:17**）時，他在描述叛逆的後果，而非表達他的意圖。孩子的死亡是受造界破碎最尖銳的證據；不是創造者漠不關心的證據。聖經中此後的一切都指向一位與死亡本身作戰並得勝的上帝。

聖經從不把死亡視為泯滅；而視為過渡。生命不以墳墓為終點。孩子在屬於任何國家或父母之前，先屬於上帝。當孩子離世，純真回到賜之者那裡。這場悲劇顯明受造界的破碎；並非神憐憫的缺席。

死亡藉著罪進入人間（**羅馬書 5:12**）；萬有也在其後果下嘆息（**羅馬書 8:22**）。然而，神的公義與慈愛懷抱每一個過早結束的生命。聖經一貫顯示，孩子在祂的眷顧與憐憫之下。

**經文支持：**

- **創世記 2:17**：「你喫的日子必定死。」  
  死亡是叛逆的後果，不是上帝對人類原初設計的一部分。

- **撒母耳記下 12:22–23** : 孩子死後，大衛說：「我必往他那裡去；他卻不能回我這裡來。」  
  這表明大衛確信孩子在神那裡；並且在死後仍有相聚。

- **以賽亞書 57:1–2** : 「義人死亡，無人放在心上……他們得享平安；凡正直行事的，各人在牀上安歇。」  
  早逝有時乃是憐憫，使其免受將來的災禍。

- **馬太福音 19:14** : 耶穌說：「讓小孩子到我這裡來，不要禁止他們；因為在天國的，正是這樣的人。」  
  基督宣告對每個孩子的接納與歸屬。

- **申命記 1:39** : 上帝在審判中眷顧以色列的孩童，說他們「還不曉得分別善惡」。  
  道德責任需要認知；無知的幼小在恩典中蒙保守。

- **傳道書 12:7** : 「塵土仍歸於地；靈仍歸於賜靈的神。」  
  萬有都歸回其源頭。

死亡並非神起初的旨意；然而藉著基督的復活，死亡成了被勝過的仇敵。  
**哥林多前書 15:54–55** : 「死亡被得勝吞滅……死啊，你的毒鉤在哪裡？」

**羅馬書 8:38–39** 確信，沒有什麼能使我們與神的愛隔絕；連「生」與「死」也不能。夭折的孩子並非歸於虛無；他們安息在那不變的愛中。

痛與喪仍是真實的；但聖經的脈絡顯示，神保守無辜者，並在祂的時間裡更新萬有。  
**啟示錄 21:4** 的應許是：「神要擦去他們一切的眼淚；不再有死亡。」

死亡看似終結了純真；其實，它把純真安然交到永恆者的懷中。

### **7. 為什麼上帝在舊約中命令戰爭或使用暴力？**

聖經將這些命令呈為**有限的審判行動**、**對腐蝕性邪惡的防護**、以及**在嚴苛約束下的暫時性措施**；並非給予暴力的常設許可。以色列一再被告誡不可說「因我們的義」而得地；審判臨到，是因長期根深蒂固的罪惡，如流血與焚子獻祭；且因上帝是列國的審判者。

**經文支持：**

- **申命記 9:4–6** : 以色列不可自誇「因我的義」；而是因列國的罪惡，以及神對列祖的應許。

- **創世記 15:16** : 「亞摩利人的罪孽還沒有滿盈。」  
  神在審判前有長久忍耐；直到邪惡「成熟」。

- **利未記 18:24–28** : 因強暴與可憎之事，那地「把他們吐出」；以色列若效法，也必同受。

- **申命記 12:31** : 列國「將自己的兒女在火中焚燒，獻與他們的神」。  
  戰事常與止息暴行相連；非為赤裸的掠奪。

**戰爭的規則與限制：**

- **申命記 20:10–12** : 攻打遠方城邑，先要宣告和睦；對方若拒絕並交戰，方可圍攻。

- **申命記 20:19–20** : 不可在戰時砍伐結果子的樹木；即使行審判，也受關乎未來生命的約束。

- **申命記 24:16** : 「不可因子殺父，也不可因父殺子。」  
  強調個人責任。

**兼具公義與憐憫的個案：**

- **約書亞記 2；6:25** : 迦南人喇合因信投靠耶和華而得存留，並被接納進以色列；悔改者皆可蒙憐。

- **約拿書 3:4–10** : 暴虐的外邦大城悔改而獲赦免；表明神的本意是在轉向中施行復興。

- **以西結書 33:11** : 神不喜悅惡人死亡；祂呼召人轉回得生。

**為何有些命令顯得嚴厲：**

- **申命記 7:1–5；20:16–18** : 驅逐特定列邦，為阻止以色列沾染其宗教與風俗；目標是守約，與種族至上無涉。

- **撒母耳記上 15:2–3** : 因亞瑪力人無故的殘暴而受審；聖經視之為對持續侵害的歷史性裁決。  
  同樣的經文後來也審判以色列，當他們自己變得殘暴與不義時。

**神以同一標準審判以色列：**

- **列王紀下 17:7–23** : 北國因與列國同樣的罪被擄。

- **耶利米書 25:8–11** : 南國猶大因偶像與不義而受巴比倫之罰。

**走向和平與新約的軌跡：**

- **以賽亞書 2:4** : 「要將刀打成犁頭；矛打成鐮刀。」

- **彌迦書 6:8** : 「行公義、好憐憫、存謙卑的心與神同行。」

- **馬太福音 5:9；5:38–44** : 耶穌稱「使人和睦的人有福了」；教導愛仇敵，否定個人報復。

- **羅馬書 12:19** : 「不要自己伸冤；寧可讓步，聽憑主怒……主說：伸冤在我，我必報應。」  
  伸冤權在神，不在私人手中。

**聖經總結：** 舊約中的戰事命令被描繪為對根深之惡的階段性審判；在嚴格限制下執行；並向轉回者敞開憐憫。神也以同一標準審判以色列。先知書與新約把目光指向神國降臨時戰爭的終止，以及信徒被呼召作和平之子。

### **8. 慈愛的上帝怎會把人送入地獄？**

首先：地獄從來不是為人類造的。耶穌親口在 **馬太福音 25:41** 說：「你們這被咒詛的人，離開我，進入那**為魔鬼和他的使者所預備的**永火裏去。」地獄是為撒但和背叛上帝的墮落天使而設的審判之所；它從未被設計為任何人的歸宿。

聖經並不把地獄呈為神的殘忍；乃是人類選擇的最終後果。神尊重祂所賜的自由；愛無法被強迫，拒絕祂的同在自然會走向與祂分離。地獄，正是那種分離的永久化。

救贖藉著基督的恩典向萬人敞開；不能靠行為賺取；必須憑信領受。  
**以弗所書 2:8–9** 說：「你們得救是本乎恩，也因著信；這並不是出於自己，乃是神所賜；也不是出於行為，免得有人自誇。」  
接受這份禮物的人，罪得赦免並被恢復生命；拒絕的人選擇自己承擔罪債，結果就是與神分離。

**經文支持：**

- **以西結書 33:11** : 主宣告祂「不喜悅惡人死亡，惟喜悅惡人轉離所行的道而活」。  
  神的心意是悔改；不是定罪。

- **彼得後書 3:9** : 主「乃是寬容你們，不願有一人沉淪，乃願人人都悔改」。  
  審判只在忍耐耗盡之後臨到。

- **申命記 30:19** : 「我將生與死擺在你面前……所以你要揀選生命。」  
  神賜下選擇；不強迫結局。

- **羅馬書 2:5–8** : 心硬的人「為自己積蓄忿怒」，恆求善與榮耀的人得永生。  
  審判隨著對惡的執意而來。

- **馬太福音 25:41-46** : 耶穌談到末後的分判：「你們這被咒詛的人，離開我！進入那為魔鬼和他的使者所預備的永火裡去……這些人要往永刑裡去；那些義人要往永生裡去。」  
  判決繫於拒絕憐憫；不是缺乏機會。

- **約翰福音 3:18–19** : 「信的人不被定罪；不信的人罪已經定了……光來到世間，世人因自己的行為是惡的，不愛光，倒愛黑暗。」  
  定罪源於偏愛黑暗而拒絕光。

- **羅馬書 1:24–26** : 神「任憑他們」隨從私慾。  
  分離從人心執迷獨立之時便開始。

**地獄所指為何：**

地獄被描繪為與神的面與祂的榮光隔絕；也因此與一切善分離。

- **帖撒羅尼迦後書 1:9** : 「他們要受永遠沉淪的刑罰，離開主的面和祂權能的榮光。」  
  損失首先是關係性的；非僅物理性的。

- **馬太福音 13:41–43** : 邪惡被「從祂的國裡挑出來」；「那時義人在他們父的國裡要發光，如同太陽。」  
  公義要求除去毀壞和平之物。

- **啟示錄 20:11–15** : 「人都照他們所行的受審判。」  
  審判是個人且與行為相稱的。

**為何愛必然包含審判：**

完全的愛也必然要求完全的公義。  
若神對殘忍、剝削或不悔改的邪惡置之不理，祂就稱不上良善。  
那位拯救的愛，也拒絕讓惡不受對付。  
十字架上，憐憫與公義相遇：救贖的代價已經付清，為要「顯明祂自己為義，也稱那信耶穌的人為義」（**羅馬書 3:25–26**）。

**聖經總結：**  
地獄存在，並非因為神所願；而是因為神尊重人的自由。  
藉著基督，救恩作為恩典的禮物臨到眾人；藉著信而得，不由行為。  
接受者進入生命；拒絕者按自己的選擇仍舊分離。  
審判確認了這個選擇：拒光者永遠分離；擁抱光者得享永生。

### **9. 為什麼需要「信心」；為什麼不是直接給人「確鑿的確定性」？**

聖經將信心定義為對未見之事的確據；並非對真理的無知。  
**希伯來書 11:1** : 「信就是所望之事的實底，是未見之事的確據。」  
信心搭起了人類有限與神聖現實之間的橋樑。  
若神的存在以無可否認的證據強加於人，就再無信、愛與道德選擇的空間；關係會淪為強制。

信心不是「無證據的相信」；而是立基於啟示的信靠。神給出足夠的光，邀請願意的人；也保留適度的奧祕，以保護自由。  
每一次信心的回應，都是對神已然啟示的回應，藉著受造界、良知、聖經與基督自己。

**經文支持：**

- **羅馬書 1:19–20** : 「神的事情，人所能知道的，原顯明在人心裡……自從造天地以來，神的永能和神性是明明可知的……叫人無可推諉。」  
  受造界顯明神的真實；信心對此作出回應。

- **約翰福音 20:29** : 耶穌說：「那沒有看見就信的有福了。」  
  福分臨到那些越過感官證據而信的人。

- **哥林多後書 5:7** : 「因我們行事為人是憑著信心，不是憑著眼見。」  
  如今以信而行；終有一日以見完善。

- **希伯來書 11:6** : 「人非有信，就不能得神的喜悅。」  
  關係繫於自願的信靠；不是被迫的證據。

- **以弗所書 2:8–9** : 「你們得救是本乎恩，也因著信……不是出於行為。」  
  信是我們領受恩典的管道。

**為何不是「絕對的確定性」？**

被強加的確定性取消了選擇；信心則煉淨選擇。  
信心要求謙卑、依賴與愛；這些品質無法在強制下生成。  
信心的試驗生出忍耐、成熟與真實。

- **雅各書 1:3–4** : 「你們的信心經過試驗就生忍耐；但忍耐也當成功，使你們成全完備，毫無缺欠。」

- **彼得前書 1:7–9** : 「你們的信心既被試驗，就比那被火試驗仍能壞的金子更顯寶貴……可以得著靈魂的救恩。」  
  如今未見之事，終將顯明。

**聖經總結：**  
信心不是盲目；乃是建立在啟示上的信靠。  
神顯明到足以引導人信；也隱藏到足以護衛自由。  
當那日到來，「我們必要像祂，因為必得見祂的真體」（**約翰一書 3:2**）。  
在此之前，信心是愛、信任與救恩得以自由存在的道路。

### **10. 既然上帝知道撒但會背叛，為什麼還創造了他？**

聖經啟示：撒但並非被造時即為邪惡；他原是光明的受造者，卻因驕傲與自我高舉而敗壞。  
上帝創造一切有智能者，天使與人，都賦予真實的自由。  
這自由使愛成為可能；也允許叛逆的發生。神預知撒但的墮落，卻允許之，為使道德宇宙真實存在；而非「被編程」的幻境。

**經文支持：**

- **以西結書 28:12–17** : 藉描述推羅王而使用近乎天上存在者的語言：「你從受造之日所行的都完全，直到在你中間察出不義。」  
  驕傲腐化了原本的完全。

- **以賽亞書 14:12–15** : 「明亮之星、早晨之子啊，你何竟從天墜落……你心裡曾說：我要升到天上；我要高舉我的寶座……」  
  叛逆始於自我高舉與拒絕順服。

- **提摩太前書 3:6** : 驕傲被稱為「魔鬼所受的刑罰」。  
  墮落源自自高；非出於神的設計。

- **約翰福音 8:44** : 耶穌稱撒但是「從起初就是殺人的；不守真理」，且是「說謊之人的父」。

- **彼得後書 2:4** : 「就是天使犯了罪，神也沒有寬容。」  
  連天使也要受公義的對待。

**為何神允許叛逆：**

若自由沒有違背的可能，就不是真自由。  
若愛不可被拒絕，就不是真愛。  
神允許叛逆，為顯明良善的真實；揭露邪惡的自我毀滅；並藉救贖彰顯祂的公義與憐憫。

- **羅馬書 9:22–23** : 神「多多忍耐那可怒預備遭毀滅的器皿」，為要「將祂榮耀的豐富彰顯在那蒙憐憫的器皿上」。  
  神的忍耐同時顯明審判與慈悲。

- **約伯記 1:6–12** : 即便在試煉中，撒但仍受神界限的拘束；叛逆被允許，卻不失控。

- **啟示錄 12:7–9** : 「天上就有了爭戰……大龍被摔下去。」  
  邪惡終被擊敗；絕非與神同等。

**結局：**

神甚至使叛逆也最終服事祂的計畫。  
藉著基督，「天上地下所有的權柄」都歸給祂（**馬太福音 28:18**）。  
末後的審判將永遠終結罪惡的存在（**啟示錄 20:10**）。

**聖經總結：**  
撒但起初被造為善；因驕傲墮落。神允許叛逆，使自由與愛得以真實。  
邪惡是暫時且自我敗壞的；神的主權與公義終必得勝。  
最後，叛逆顯露其虛無；神的真理與完全被更加顯明。

### **11. 既然真理只有一個，為什麼會有那麼多宗教？**

聖經教導：上帝藉著受造界與良知清楚啟示自己，讓萬人可以尋求祂。隨著時間推移，人類扭曲了這認識，形成了夾雜真理碎片與謬誤的人間宗教。  
宗教的多樣性並不意味著真理相對；而是說明啟示被不完全地領受，並被墮落的理解所過濾。  
然而，聖經也肯定，神從未不在列國中給自己留見證。

自起初，神旨意萬民認識祂。祂揀選以色列，為要保存啟示，並藉其帶出彌賽亞，使「地上的萬族都要因你得福」（**創世記 12:3**）。耶穌宣告自己是這啟示的豐滿；是一切微光所當度量的真光。

同時，聖經啟示，錯誤的敬拜並非僅是人的混亂；往往源於屬靈的背叛。墮落的天使，即「執政的、掌權的」，企圖扭曲神的真理，使人陷於偶像與敗壞。  
這些黑暗權勢假冒「神明」，索取祭品，歪曲倫理，與神的真理為敵。

**經文支持：**

- **羅馬書 1:19–23** : 「神的事情，人所能知道的，原顯明在人心裡……自從造天地以來，神的永能和神性是明明可知的……他們將不能朽壞之神的榮耀變為偶像。」  
  宗教常以對神性的認識開始；卻滑向偶像崇拜。

- **申命記 32:16–17** : 「祭祀鬼魔，並非祭祀神。」  
  經文明言，許多異教的「神祇」背後是鬼魔的勢力。

- **詩篇 106:37–38** : 「他們把自己的兒女祭祀鬼魔；流無辜人的血。」  
  假宗教會墮入道德與屬靈的黑暗，包括獻孩之惡。

- **利未記 17:7** : 「他們不可再向鬼魔祭祀。」  
  神禁止以色列追隨披著「神明」外衣的鬼魔影響。

- **哥林多前書 10:19–20** : 「外邦人所獻的祭是祭鬼，不是祭神。」  
  偶像崇拜不是中立的；背後有屬靈勢力。

- **以弗所書 6:12** : 「我們並不是與屬血氣的爭戰，乃是與那執政的、掌權的、管轄這幽暗世界的，以及天空屬靈氣的惡魔爭戰。」  
  宗教的迷惑屬於更廣泛的屬靈爭戰。

- **使徒行傳 17:26–27** : 神「要叫他們尋求神……其實他離我們各人不遠」。  
  各族羣文化裡都有指向造物主的迴響。

- **約翰福音 1:9** : 耶穌是「那光、照亮一切生在世上的人」。  
  一切片段性的真理都在祂裡面得以成全。

- **約翰福音 14:6** : 「我就是道路、真理、生命；若不藉著我，沒有人能到父那裡去。」  
  真理是獨一的；神的憐憫卻臨到萬民。

- **提摩太前書 2:3–4** : 神「願意萬人得救、明白真道」。  
  人類信仰的多元，既反映尋神的渴望，也顯出神的恆久忍耐。

- **羅馬書 10:12–13** : 「猶太人和希利尼人並沒有分別……凡求告主名的，就必得救。」  
  救贖向普世開啟；真理仍是唯一。

**總結：**  
宗教之多，是因為人類保留著對上帝的記憶，卻沒有祂啟示的豐滿。有的歪曲來自人的誤解；有的則出自鬼魔的偽造與攪擾。  
創造與良心仍為造物主作證；但惟有在基督裡，這一切才被完全揭開。  
耶穌不是眾多道路之一；祂是所有誠心尋真之路的成全者；是顯明虛假並拯救歸向祂之人的真光。

### **12. 既然上帝可以直接赦免，我們為何仍需要「得救」？**

赦免不是對罪一筆勾銷；而是關乎真理與公義。  
若神簡單地忽略罪，祂就不再是義者。  
完全的良善不能讓惡無後果；否則公義與聖潔將被否定。  
聖經說：「罪的工價乃是死」（**羅馬書 6:23**）；這不是任意的懲罰；而是與生命之源隔絕的道德現實。

為使愛與公義和好，上帝藉著祂的兒子提供了救贖。  
耶穌親自承擔罪的刑罰；既滿足了公義，也向人施以憐憫。  
這救恩是禮物，白白賜下；不是靠行為賺取；必須憑信領受。  
領受者被祂的義所遮蓋；拒絕者仍在罪的後果之下，即與神隔絕。

**經文支持：**

- **羅馬書 3:23–26** : 「世人都犯了罪，虧缺了神的榮耀；如今卻蒙神的恩典，因基督耶穌的救贖，就白白稱義……為要顯明祂自己為義，也稱那信耶穌的人為義。」  
  神的赦免立於祂的公義之上；不是繞開公義。

- **希伯來書 9:22** : 「若不流血，罪就不得赦免。」  
  生命償付生命；在基督的獻祭裡成全。

- **以賽亞書 53:5–6** : 「那知祂為我們的過犯受害……耶和華使我們眾人的罪孽都歸在祂身上。」  
  受苦的僕人擔當人該受的懲罰。

- **彼得前書 2:24** : 「祂被掛在木頭上，親身擔當了我們的罪；使我們既然在罪上死，就得以在義上活。」  
  救恩不只赦免；也改變生命。

- **以弗所書 2:8–9** : 「得救是本乎恩，也因著信……不是出於行為。」  
  恩典是禮物；卻需要人領受。

- **約翰福音 3:16–18** : 「神愛世人，甚至將祂的獨生子賜給他們……信祂的人不被定罪；不信的人罪已經定了。」  
  拒絕恩典，債務仍未清償。

- **哥林多後書 5:21** : 「神使那無罪的替我們成為罪，好叫我們在祂裡面成為神的義。」  
  十架是代替與交換；我們的罪換取祂的義。

**聖經總結：**  
救恩之必要，在於赦罪不能違背真理。  
神的公義要求代價；神的愛親自付上。  
在基督的犧牲裡，憐憫與公義相會。  
救恩不是賺取；而是憑信領受；這是在不損害神公義的前提下，赦免罪的惟一道路。
