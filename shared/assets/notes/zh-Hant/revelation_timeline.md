# 啟示錄末世時間線

本時間線以對啟示錄的**直白的未來派、前千禧年解讀**為主要框架：基督在啟示錄19章有形地再臨，隨後撒但被捆綁；聖徒在啟示錄20章與基督一同作王一千年；此後撒但被釋放，最後的審判隨之而來；直到那時，啟示錄21-22章才描述新天、新地和新耶路撒冷。

啟示錄包含異象、插敘、回顧和解釋性場景，因此不能把每一章都當作約翰在給出一條現代秒錶式的時間線。啟示錄12章就是明顯的例子，因為它在描述末世迫害之前，先回溯到彌賽亞的降生和昇天。

啟示錄陳明異象、警告、審判、基督的勝利、復活、最後審判和新創造，卻沒有提供一張所有讀者都認可的總圖。本筆記中的**明文**，是指經文說出了相關事件或內容。把不同異象連接起來、指定日期，或判斷它們先後還是重疊的時間線，都屬於**綜合解釋**，即使這種解釋讀來很自然。

「啟示文學」描述啟示錄以異象和象徵表達的預言文學形式。它不表示本書屬於次經或偽經，也不否認其中應許的真實性。

### 確信程度標籤

- **明文：** 經文直接說明該事件或次序。
- **順序推論：** 該次序從約翰異象的先後自然得出，但經文沒有提供日曆日期。
- **解釋：** 基督徒對其位置或象徵意義意見不一。

## 解釋路徑

要把啟示錄與它所採用的經文一同閱讀。但以理看見諸獸、天上的法庭和領受權柄的人子；約翰在獸與基督得勝的異象中發展這些主題（但以理書7:1-14；啟示錄13:1-7；啟示錄19:11-21）。以西結看見上帝的居所和賜生命的河；啟示錄以上帝住在他的子民中間和生命河結束（以西結書47:1-12；啟示錄21:3；啟示錄22:1-5）。這些聯繫先幫助解釋形象，隨後才能把事件放進圖表。

以下時間線由三個不同問題塑造。解釋路徑討論一個異象描繪哪一段時期；千年國問題討論一千年怎樣與基督再臨相關；被提時機討論信徒何時復活迎見主。選擇一個答案，不會自動解決另外兩個。每一種觀點都必須解釋基督真實再臨、復活、審判和新創造（使徒行傳1:9-11；約翰福音5:28-29；啟示錄20:11-21:5）。

### 未來主義：異象走向最後危機

未來主義把啟示錄4-22章的大部分內容放在基督將來再臨前後的事件中。最強理由在約翰描寫的結局：獸被擊敗，聖徒復活，撒但最終毀滅，受造界不再有死亡（啟示錄19:19-21；啟示錄20:4-10；啟示錄21:1-4）。這些應許超越七個教會當時的處境。

這個框架也把但以理最後的苦難，與耶穌關於可憎之物和大患難的警告相連（但以理書12:1-3；馬太福音24:15-31），又把獸的逼迫和有限權柄與這些經文一起讀（啟示錄13:5-10）。異象因此面向未來，卻沒有使給約翰第一批讀者的警告失效。基督當時已經要求那些教會拒絕妥協、忍受逼迫（啟示錄2:10；啟示錄2:20-25）。

**時間線：** 歷史中的教會和現在的忍耐 -> 最後危機 -> 基督得勝 -> 復活、審判和上帝國度完成。未來主義前千年國說把千年統治放在最後審判之前，詳細次序見下文。

### 部分過去主義：近處的審判與將來的完成

部分過去主義從啟示錄寫給真實的教會，以及時候近了的聲明開始（啟示錄1:1-4；啟示錄22:6-10）。它把許多審判語言與一世紀的衝突相連。耶穌關於耶路撒冷、圍城和那個世代的警告，是主要比較依據（路加福音21:20-24；馬太福音24:34）。有些人強調耶路撒冷陷落，另一些人強調羅馬及其逼迫。除了經文以外，這些認定還需要歷史論證。

這種路徑可以把早期審判看作基督權柄的展示，而不把它等同於最後的身體復活。啟示錄本身區分歷史中的審判與死亡終結和最後審判（啟示錄18:1-24；啟示錄20:11-21:4）。這裡說明的部分過去主義仍期待耶穌照使徒行傳1:11的應許，以身體再臨；它沒有把每項未來應許都看作已經完成。

**時間線：** 一世紀的逼迫和審判 -> 持續的福音使命和基督統治 -> 將來的身體再臨、復活和最後審判 -> 新創造。許多人把這條路徑與無千年國說或後千年國說結合。

### 歷史主義：貫穿教會歷史的長序列

歷史主義把異象讀作從使徒時期走向基督再臨的漫長教會衝突記載。但以理接續出現的列國提供模式：一個預言異象可以跨越多個地上權勢，直到上帝最後得勝（但以理書2:31-45；但以理書7:17-27）。啟示錄同樣經過衝突、忍耐和基督統治（啟示錄1:9；啟示錄13:10；啟示錄20:4）。

困難在於把某一印、號或獸認定為後來一個具體制度或事件。啟示錄沒有提供中世紀或現代名稱清單。有些歷史主義計算採用一日頂一年的原則，比較民數記14:34和以西結書4:6。那些經文中，上帝為一個特定記號或審判明確規定換算；要把它應用於別處，必須從那段經文的上下文論證。

**時間線：** 使徒時代的教會 -> 接續的歷史衝突和審判 -> 基督最後得勝 -> 復活、審判和新創造。不同歷史主義圖表對中間事件的分配各異；共同主張是異象長久跨越歷史。

### 理想主義：基督統治下反覆出現的衝突

理想主義強調歷代信徒都會面對的模式：強制性的權勢、欺騙性的宗教、腐敗的財富、忠信的見證和上帝的審判。約翰自己的處境已經把患難、神國和忍耐連在一起（啟示錄1:9）。獸和巴比倫的異象尚未展開，七個教會已經面對苦難和妥協壓力（啟示錄2:9-10；啟示錄2:13-16；啟示錄18:3-5）。

這條路徑使異象可以教導後來的信徒，卻不用把每位新統治者都稱為最後的獸。反覆出現的模式仍可達到一個最後的歷史高潮。啟示錄以惡真正毀滅、上帝與他的子民同住結束，而不是以勝敗無盡循環結束（啟示錄20:10；啟示錄21:1-5）。

**時間線：** 基督得勝和教會見證 -> 反覆的逼迫、試探和審判 -> 最後對抗與再臨 -> 新創造。理想主義常與將來最後危機和無千年國的千年解釋結合。

## 未來主義前千禧年論

### 全部次序一覽

**七個教會 -> 寶座廳 -> 羔羊接過書卷 -> 七印 -> 七號 -> 獸與假先知 -> 七碗 -> 巴比倫傾倒 -> 基督有形再臨 -> 獸與假先知被擊敗 -> 撒但被捆綁 -> 第一次復活和一千年作王 -> 撒但被釋放 -> 最後的叛亂 -> 撒但被扔進火湖 -> 白色大寶座審判 -> 新天新地 -> 新耶路撒冷 -> 永遠作王**

### 末世審判之前：啟示錄1-5章

#### 啟示錄1章：復活的基督

約翰領受耶穌基督的啟示。他看見得榮耀的人子站在七個燈臺中間。

**關鍵經文：** 啟示錄 1:1-20。

#### 啟示錄2-3章：七個教會

耶穌向小亞細亞七個真實存在過的教會講話：

1. 以弗所
2. 士每拿
3. 別迦摩
4. 推雅推喇
5. 撒狄
6. 非拉鐵非
7. 老底嘉

這些書信包含針對真實歷史處境的教導，也一再向「得勝的」人發出應許。七個教會還代表教會歷史中連續七個時代的理論，是一種解釋，並不是啟示錄明文所說的內容。

**關鍵經文：** 啟示錄 2:1-3:22。

#### 啟示錄4章：寶座廳

約翰在異象中蒙召上去，看見神的寶座、二十四位長老、四個活物和永不止息的敬拜。

**關於被提的重要說明：** 災前被提論的教師有時把**啟示錄 4:1**中的「你上到這裡來」視為教會被提的圖景。但這節經文直接描述的是**約翰**被召進入天上的異象。因此，它至多只能算預表性的證據，並不是明文論及被提的陳述。

#### 啟示錄5章：羔羊與封印的書卷

神手中有一卷用七印封住的書卷。只有羔羊耶穌基督配展開它。

耶穌被認明為：

- 猶大支派中的獅子
- 大衛的根
- 曾被殺的羔羊

**關鍵經文：** 啟示錄 5:1-14。

### 七印

#### 第一印：白馬，征服

**啟示錄 6:1-2**

一位騎白馬的得了冠冕，出去征服，並要得勝。

**解釋：** 未來派通常把這位騎士認作征服、欺騙性的和平，或一位類似敵基督的統治者。啟示錄6章本身既沒有稱這位騎士為「敵基督」，也沒有把他稱為獸。

#### 第二印：紅馬，戰爭

**啟示錄 6:3-4**

和平從地上被奪去，人彼此殺害。

#### 第三印：黑馬，饑荒與匱乏

**啟示錄 6:5-6**

食物變得極其昂貴，油和酒卻沒有受損。

#### 第四印：灰馬，死亡

**啟示錄 6:7-8**

死亡和陰間得了權柄，可以用刀劍、饑荒、瘟疫和野獸殺害地上四分之一的人。

#### 第五印：殉道者呼求公義

**啟示錄 6:9-11**

約翰看見那些因神的道和自己的見證而被殺之人的靈魂。他們被告知要再安息片刻，等到那些也將被殺的同作僕人者數目滿足。

這確立了最後審判之前會有迫害和殉道。

#### 第六印：宇宙劇變與恐懼

**啟示錄 6:12-17**

其中包括：

- 大地震
- 太陽變黑
- 月亮顯得像血一樣紅
- 眾星墜落
- 天像書卷一樣捲起
- 山嶺海島挪移
- 君王和眾人躲避神與羔羊

他們宣告：

> 「因為祂們震怒的大日到了，誰能站立得住呢？」
>
> **啟示錄 6:17**

這印對被提的爭論極其重要，因為其中的宇宙異象與耶穌在**馬太福音 24:29-31**中的描述相似。

### 啟示錄7章：第七印之前的插敘

#### 受印的十四萬四千人

**啟示錄 7:1-8**

以色列各支派中有十四萬四千人受了印，每個列出的支派各一萬二千人。

經文兩次給出這個數目（**啟示錄 7:4; 14:1**），並逐一列出各支派的名字（**啟示錄 7:5-8**）。

#### 大群人

**啟示錄 7:9-17**

約翰看見無法數算的大群人，來自各國、各支派、各民族、各語言，站在神的寶座和羔羊面前。

經文稱他們是從大患難中出來的人。

**與被提的關係：** 神怒前被提論者常把這個場景看作信徒在第六印之後、號災之前被聚集的證據。但本章並沒有明說「這大群人就在這一刻被提」，所以這種認定仍屬解釋。

### 第七印：七號開始

**啟示錄 8:1-6**

第七印揭開時：

- 天上寂靜約有半小時
- 七位天使領受七枝號
- 眾聖徒的禱告升到神面前
- 祭壇上的火被扔到地上

按直白的順序解讀，七號從第七印展開。

### 七號

#### 第一號：地與植物受擊打

**啟示錄 8:7**

摻著血的冰雹與火降在地上。地和樹木的三分之一被燒，所有青草也被燒了。

#### 第二號：海受擊打

**啟示錄 8:8-9**

彷彿一座燃燒的大山被扔進海裡。

- 海的三分之一變成血
- 海中生物的三分之一死亡
- 船隻的三分之一被毀

#### 第三號：茵陳

**啟示錄 8:10-11**

一顆名叫茵陳的大星落在江河和眾水泉源的三分之一上。水變苦，許多人因這些水而死。

#### 第四號：天體的光變暗

**啟示錄 8:12-13**

日、月、星的三分之一受擊打，以致它們三分之一的光變暗。

隨後一隻鷹宣告三個將臨的災禍，分別對應最後三枝號。

#### 第五號：第一災，無底坑開啟

**啟示錄 9:1-12**

一顆墜落的星得了無底坑的鑰匙。像蝗蟲的生物從中出來，折磨額上沒有神印記的人五個月。

它們的王是無底坑的使者，希伯來語名叫**亞巴頓**，希臘語名叫**亞玻倫**。

#### 第六號：第二災，幼發拉底河的軍隊

**啟示錄 9:13-21**

捆綁在幼發拉底大河的四位天使被釋放。經文描述了一支龐大的騎兵；與他們有關的災害殺死了人類的三分之一。

倖存的人仍不肯悔改，不離棄偶像崇拜、殺人、邪術、淫亂和偷竊。

### 啟示錄10章：小書卷

**啟示錄 10:1-11**

一位大力天使拿著小書卷出現。約翰奉命把它吃下；它在口中甘甜，在肚腹裡卻發苦。

約翰隨後被告知，他必須再次針對許多民族、國家、語言和君王說預言。

這是插敘，不是另一枝有編號的號。

### 啟示錄11章：聖殿、兩個見證人和第七號

#### 聖城與四十二個月

**啟示錄 11:1-2**

列國踐踏聖城**四十二個月**。

#### 兩個見證人與一千二百六十日

**啟示錄 11:3-13**

兩個見證人說預言**一千二百六十日**。

最後，從無底坑上來的獸殺了他們。他們的屍體暴露三天半。神使他們復活，他們在仇敵眼前升上天去。

隨後發生猛烈的地震。

#### 第七號：國度宣告

**啟示錄 11:15-19**

第七位天使吹號：

> 「世上的國成了我主和主基督的國，祂要作王，直到永永遠遠。」
>
> **啟示錄 11:15**

天上的宣告論及神的掌權、忿怒、審判、賞賜，以及敗壞那些敗壞世界之人的時候。

**與災中被提論的關係：** 一些解釋者把保羅在**哥林多前書 15:52**所說的「末次號筒」與啟示錄第七號認作同一枝號，因此把被提置於此處。啟示錄從未明說這兩枝號就是同一枝號，所以這是一種解釋性的聯繫。

### 啟示錄12章：婦人、彌賽亞與大龍

啟示錄12章說明，為什麼不能把本書當作嚴格按章節推進的秒錶來讀。

異象包括：

- 身披日頭的婦人
- 等候吞吃她孩子的大龍
- 一個註定要轄管列國的男孩子降生
- 孩子被提到神的寶座那裡
- 婦人逃到曠野**一千二百六十日**
- 天上爭戰
- 米迦勒和他的使者擊敗大龍
- 撒但被摔下去
- 婦人及她其餘後裔遭受迫害

**啟示錄 12:5**顯然回溯到彌賽亞的降生和昇天，後面的經節則轉向與末世有關的迫害。

經文明說大龍就是：

> 「那古蛇，名叫魔鬼，又叫撒但，是迷惑普天下的」
>
> **啟示錄 12:9**

大龍攻擊那些：

> 「守神誡命、為耶穌作見證的人」
>
> **啟示錄 12:17**

### 啟示錄13章：獸、假先知與印記

#### 從海中上來的獸

**啟示錄 13:1-10**

大龍把自己的能力、座位和大權柄交給獸。

獸：

- 褻瀆神
- 掌權行事**四十二個月**
- 與聖徒爭戰
- 得權柄制伏各民族、各國、各語言和各支派
- 接受那些名字沒有記在羔羊生命冊上的人敬拜

#### 從地中上來的獸／假先知

**啟示錄 13:11-18**

第二隻獸行神蹟，促使人敬拜第一隻獸，並叫人製造獸像。

啟示錄19章後來把這位施行奇事的第二個角色稱為**假先知**。

#### 獸的印記

第二隻獸要求人在右手或額上接受印記，使任何沒有印記的人都不能買賣。

與獸有關的數字是**666**。

參見**啟示錄 13:16-18**。

### 啟示錄14章：十四萬四千人、警告和收割

啟示錄14章包含數個場景：

- 羔羊和十四萬四千人站在錫安山
- 一位天使宣告永遠的福音
- 宣告巴比倫已經傾倒
- 警告人不可敬拜獸或接受獸的印記
- 宣告在主裡而死的人有福
- 地上的莊稼被收割
- 神忿怒的酒榨

**關鍵經文：** 啟示錄 14:1-20。

其中一些場景似乎是預先顯明結局；後面的章節會更詳細地描述這些結局。

#### 第六碗：幼發拉底河乾涸，眾王聚集

**啟示錄 16:12-16**

幼發拉底河乾涸，為從東方來的眾王預備道路。邪靈把普天下的眾王聚集起來爭戰。

聚集之地名叫**哈米吉多頓**。

- 海島逃避

- 巨大的冰雹

### 啟示錄17-18章：巴比倫的解釋與毀滅

#### 啟示錄17章

約翰看見「大巴比倫」被描繪為一個騎在獸上的淫婦。本章解釋獸及與它結盟的眾王所具有的象徵性特徵。

#### 啟示錄18章

巴比倫傾倒。君王、商人和船主哀哭，因為那個讓他們獲利的經濟與政治體系在神的審判下崩潰。

神的子民受到警告：

> 「我的民哪，你們要從她裡面出來……」
>
> **啟示錄 18:4**

啟示錄只稱她為大巴比倫（**啟示錄 17:5**），沒有給她別的名字。經文稱她為「管轄地上眾王的大城」（**啟示錄 17:18**），坐在「七座山」上（**啟示錄 17:9**），並「喝醉了聖徒的血」（**啟示錄 17:6**）。經文把她描繪為一個腐敗、富有、迫害人的權勢，正處於神的審判之下。

### 啟示錄19章：婚筵與基督有形再臨

#### 天上因巴比倫受審判而歡喜

**啟示錄 19:1-5**

#### 羔羊的婚娶

**啟示錄 19:6-10**

羔羊婚娶的時候到了，新婦也預備好了。

#### 耶穌以萬王之王的身份再臨

**啟示錄 19:11-16**

天開了，耶穌騎著白馬顯現。

祂被稱為：

- 誠信真實
- 神之道
- 萬王之王、萬主之主

祂來要按公義審判和爭戰，並轄管列國。

這是啟示錄中最清楚描述有形第二次降臨的場景。

#### 獸與假先知被擊敗

**啟示錄 19:17-21**

獸和地上的眾王聚集，要與基督爭戰。

獸和假先知被擒拿，活活地扔進火湖。

他們的軍隊被擊敗。

### 啟示錄20章：千禧年國度

#### 撒但被捆綁一千年

**啟示錄 20:1-3**

一位天使捉住撒但，把他捆綁，扔進無底坑，將無底坑關閉並封印，使他在一千年完結以前不能再迷惑列國。

這就是直白的前千禧年解讀把千禧年國度置於啟示錄19章基督再臨**之後**的原因。

敘事次序是：

**基督再臨 -> 獸與假先知被擊敗 -> 撒但被捆綁 -> 一千年作王**

#### 第一次復活並與基督一同作王

**啟示錄 20:4-6**

約翰看見一些寶座和那些得了審判權柄的人。他看見那些因給耶穌作見證並因神之道被斬首之人的靈魂，以及沒有敬拜獸或獸像、也沒有受獸印記的人。

他們復活，與基督一同作王**一千年**。

啟示錄稱這是：

> 「第一次復活」
>
> **啟示錄 20:5**

有分於這復活的人作神和基督的祭司，並與祂一同作王一千年。

**與被提的關係：** 災後被提論者認為，「第一次復活」位於啟示錄19章之後，強有力地證明信徒的復活與聚集發生在基督有形再臨之時。災前被提論者通常把「第一次復活」理解為分階段進行的一個類別或計劃，認為教會在更早時復活，患難中的殉道者則在這裡復活。啟示錄本身沒有明文描述這些被主張的階段。

### 千禧年後撒但被釋放

**啟示錄 20:7-10**

一千年完結後：

1. 撒但從監牢中被釋放。
2. 他再次迷惑列國。
3. 歌革和瑪各聚集爭戰。
4. 他們圍住聖徒的營和蒙愛的城。
5. 火從天降下燒滅他們。
6. 撒但被扔進火湖。

獸和假先知已經在那裡，因為他們早在千禧年之前，就於啟示錄19章中被扔進火湖。

這一細節表明，千禧年國度**不是**最終的新創造。一千年後撒但最後一次被釋放，因此屆時仍有可能發生叛亂。

### 白色大寶座審判

**啟示錄 20:11-15**

撒但最終被擊敗後：

- 一個白色大寶座出現
- 天地從神面前逃避
- 死人站在寶座前
- 案卷展開
- 生命冊展開
- 死人照各自所行的受審判
- 死亡和陰間被扔進火湖
- 凡名字沒有記在生命冊上的人都被扔進火湖

這就是第二次的死。

只有在千禧年、撒但獲釋、最後叛亂和白色大寶座審判之後，約翰才說：

>
> **啟示錄 21:1**

聖城新耶路撒冷由神那裡從天而降。

接下來是聖經最核心的應許之一：

> 「看哪，神的帳幕在人間。祂要與人同住。」
>
> **啟示錄 21:3**

在新創造中：

- 神與人同住
- 不再有死亡
- 不再有悲哀
- 不再有哭號
- 不再有疼痛
- 以前的事都過去了
- 神將一切都更新

參見**啟示錄 21:1-8**。

本章餘下部分描述新耶路撒冷的榮耀。

### 啟示錄22章：永生與最後的應許

啟示錄以這些景象結束：

- 生命水的河
- 生命樹
- 神和羔羊的寶座
- 神的僕人得見祂的面
- 咒詛被除去
- 神的僕人作王，直到永永遠遠

參見**啟示錄 22:1-5**。

耶穌一再說祂必快來，並發出最後的邀請，叫人前來白白取生命的水喝。

參見**啟示錄 22:7, 12, 16-17, 20**。

### 千禧年與新創造是不同階段

這一區分至關重要。

| 千禧年國度 | 新天新地 |
|---|---|
| 啟示錄 20:1-10 | 啟示錄 21:1-22:5 |
| 持續一千年 | 永恆 |
| 撒但被捆綁 | 撒但永遠在火湖中 |
| 撒但後來被釋放 | 此後再無撒但的叛亂 |
| 列國仍然存在，後來仍可能受迷惑 | 汙穢之物絕不進入新耶路撒冷 |
| 以最後的叛亂告終 | 不再有死亡、悲哀、哭號或疼痛 |
| 此後是白色大寶座審判 | 在最後審判之後 |

按照直白的順序解讀，完全顯現的千禧年國度**尚未發生**，因為啟示錄把它放在基督再臨時有形地擊敗獸與假先知之後，又放在撒但最後獲釋之前。

### 啟示錄是否教導七年大患難？

啟示錄反覆給出約三年半的時段：

- **四十二個月**：啟示錄 11:2
- **一千二百六十日**：啟示錄 11:3
- **一千二百六十日**：啟示錄 12:6
- **一載、二載、半載**：啟示錄 12:14
- **四十二個月**：啟示錄 13:5

一種常見的未來派解釋把這些時段與**但以理書 9:27**最後的「一七」結合，構成一個分為前後兩個約三年半階段的七年末世時期。

這可能是合理的經文協調方式，但必須把經文本身與解釋模型區分開來：

**啟示錄本身從未出現「患難持續七年」這句話。**

七年框架來自把啟示錄與但以理書結合起來。

## 未來主義前千禧年論: 重疊異象

這個觀點保留啟示錄19-22章的前千年結局，同時容許有些異象覆蓋同一時期。約翰看見異象的次序，不必總能確定其中事件從何時開始。啟示錄提供清楚例子：第七號宣告神國後，啟示錄12章回到彌賽亞出生和被高舉（啟示錄11:15-18；啟示錄12:1-6）。

**簡短時間線:** 教會時代 -> 重疊並加劇的審判異象 -> 基督有形再臨 -> 千禧年統治 -> 撒但最後叛亂 -> 最後審判 -> 新創造。

### 跟隨反覆出現的終點

第六印達到天象震動，並宣告烈怒的大日（啟示錄6:12-17）。第七號宣告神國、烈怒、審判和上帝僕人得賞（啟示錄11:15-19）。第七碗宣告完成，又帶來空前的地震和巴比倫受審判（啟示錄16:17-21）。看見重疊循環的讀者比較這些終點，不假定每個系列都增加一段完全不同的年數。

出埃及的災禍也解釋這些審判的語言。血、黑暗和冰雹使人想起上帝對抗埃及（出埃及記7:17-21；出埃及記9:22-26；出埃及記10:21-23；啟示錄8:7-9；啟示錄16:3-10）。共同背景解釋異象為何相似，但相似本身不能證明兩項審判同時發生。

### 先比較各段時期，再把它們相加

啟示錄11:2-3把聖城受踐踏四十二個月，與一千二百六十日的見證並列。啟示錄12:6和啟示錄12:14以一千二百六十日和一載二載半載描述婦人受保護。啟示錄13:5給獸四十二個月權柄。這些描述邀請讀者與但以理書7:25和但以理書12:7比較，卻沒有命令人把每一次出現都相加成更長總數。

任何重疊提議都應認定其中的人、行動、持續時間和終點。婦人受保護和獸施行逼迫，可以描寫同一衝突的對立雙方；它們同時存在，不會抹去兩者差異（啟示錄12:13-17；啟示錄13:5-10）。經文給出事件和時期，怎樣對齊仍是讀者的綜合。

### 區分預告與後來的解釋

天使在啟示錄14:8宣告巴比倫傾倒，啟示錄17-18章隨後才解釋她的性質和毀滅。啟示錄17:1明確引入對淫婦受審判的解釋。把這個解釋放在七碗之後閱讀，不需要巴比倫倒下兩次。

因此，未來主義的重述說保留向前推進，卻不把每個場景強塞進一個新的時間格。它也讓被提時機留待單獨研究。讀者可以期待將來的千年國，同時把復活和聚集放在患難前、最後危機期間，或基督公開再臨時。相關經文必須確立這個位置，異象重疊本身不能確立（馬太福音24:29-31；帖撒羅尼迦前書4:16-17）。

## 歷史性前千禧年主義

歷史前千年國說期待基督在將來地上統治之前再臨。它通常把教會復活和聚集連到患難後基督公開再臨，不要求教會早幾年被移走才能保住上帝給他子民的應許。

**簡短時間線:** 當前教會時代 -> 加劇的患難和背道 -> 有形再臨、復活、信徒聚集 -> 千禧年統治 -> 最後叛亂 -> 最後審判 -> 新創造。

### 把來臨和聚集一起讀

耶穌描述人子在患難之後顯現，聚集他的選民（馬太福音24:29-31）。保羅描述基督降臨，死去信徒復活，活著的信徒與他們聚集（帖撒羅尼迦前書4:13-18）。後來，他在討論背道和不法之人時，把基督來臨與我們聚集到他那裡放在一起（帖撒羅尼迦後書2:1-8）。歷史前千年國說把這些記載連成一次高潮性的來臨。

這樣理解盼望，不要求信徒逃避一切苦難。耶穌使門徒預備面對患難，啟示錄呼召聖徒在獸的逼迫下忍耐（約翰福音16:33；啟示錄13:10）。上帝拯救人免受烈怒的應許仍然堅定；這個觀點把它與免受逼迫區分（帖撒羅尼迦前書5:9-10）。

### 閱讀兩次失敗之間的統治

啟示錄19:19-21描述獸和假先知失敗。啟示錄20:1-6接著描述撒但被捆綁，以及有分於第一次復活的人作王。一千年後，撒但召集另一場反叛，上帝毀滅它（啟示錄20:7-10）。歷史前千年國說把這個進程讀作接續事件，並把第一次復活理解為身體復活。

保羅給出相關次序：基督復活；屬基督的人在他來臨時復活；隨後是末期，那時他戰勝一切仇敵，把國交給父（哥林多前書15:23-28）。這段經文支持基督得勝掌權，卻沒有說明間隔多長。這個綜合由啟示錄20章提供一千年。

### 解釋應許的全部內容

前千年國讀者把將來統治與一些經文相連，這些經文描繪列國中的公義，同時仍有尚未徹底廢除死亡的狀況（以賽亞書11:1-10；以賽亞書65:20-25；撒迦利亞書14:16-19）。其他基督徒從現今神國或新創造的角度閱讀這些應許。關鍵問題是這些經文如何與啟示錄20章相連，不是上帝是否守約。啟示錄21:4仍是最後的地平線：死亡本身終止。

## 無千禧年論

無千年國說把一千年理解為基督現今與聖徒一同掌權，而不是他再臨後的另一個地上時代。它承認真實的神國和將來的身體復活。它的中心解釋把啟示錄20:1-6看作基督初臨與再臨之間時代的另一個視角。

**簡短時間線:** 基督第一次降臨及現今天上掌權 -> 教會時代的福音使命、苦難和反覆衝突 -> 短暫的最後叛亂 -> 一次有形再臨、普遍復活和最後審判 -> 新創造。

### 把撒但受捆綁與基督初臨一起讀

啟示錄20:3說明捆綁撒但的目的：在他被釋放以前，不讓他迷惑列國。耶穌把自己的工作描述為先捆住壯士，再進入他的家（馬太福音12:28-29）。在十字架之前，他宣告世界的王受審判，也說自己被舉起時要吸引萬人歸向他（約翰福音12:31-33）。無千年國讀者把這些經文與福音在列國中的推進相連。

他們因此把捆綁理解為限制撒但的權勢，而不是撒但的一切活動都不存在。使徒仍警告信徒防備魔鬼，所以這個區分很重要（彼得前書5:8-9）。前千年國讀者則回答說，被關在封住的無底坑中，描述的是比現今世界可見的更強限制（啟示錄20:1-3）。兩種解釋都必須說明經文所說的目的和異象形象的力度。

### 閱讀聖徒的生命和與基督一同掌權

約翰在啟示錄20:4看見忠信殉道者的靈魂，正如他早先看見等候伸冤的殉道者靈魂（啟示錄6:9-11）。無千年國的一種解釋把他們活著掌權認作他們現在在天上與基督同活；另一種解釋強調信徒現在有分於基督復活的生命（以弗所書2:4-6；約翰福音5:24-25）。這些解釋在同一觀點內部也不同，但兩者都不否認後來身體復活。

主要困難在於約翰說他們活了，其餘死人還沒有活，直等一千年完了（啟示錄20:4-5）。前千年國說把兩處相同表達都讀作身體復活。無千年國說區分聖徒現在勝過死亡與最後復活，並藉著天上靈魂的異象和新約關於在基督裡得生命的教導閱讀本段。

### 把再臨讀作最後完成

耶穌在關於將到之時的教導中，把義人和惡人復活放在一起（約翰福音5:28-29）。他也把榮耀再臨與審判萬民相連（馬太福音25:31-46）。彼得把主的日與審判和應許的新天新地相連（彼得後書3:10-13）。無千年國說把復活、審判和新創造放在基督再臨時，就優先考慮這些經文。

這種解釋依賴把啟示錄20章看作重述，而不是啟示錄19章以後開始的接續事件。這樣，一千年表達上帝為現今統治所定的完整時期，隨後是撒但短暫釋放和最終失敗（啟示錄20:3；啟示錄20:7-10）。這個觀點的確信建立在基督現今掌權和應許再臨上，不在於否認神國的現實。

## 後千禧年論

後千年國說期待福音在基督再臨前，使列國廣泛信主、順服。它把這個期待與千年國相連，並把千年國理解為現今時代或其中後來一段興盛時期。它所盼望的是基督藉福音作工，不是離開基督的人類自行改善。

**簡短時間線:** 當前時代的福音使命 -> 列國廣泛歸信和國度影響的漫長時期 -> 最後叛亂 -> 有形再臨、復活、最後審判 -> 新創造。

### 從君王的權柄和使命開始

復活的耶穌宣告自己擁有天上地下所有權柄，差遣門徒使萬民作門徒（馬太福音28:18-20）。詩篇2:7-9把列國呈現為聖子的產業。詩篇72:8-11描繪君王廣闊的權柄和列國的服事。後千年國說把使命與這些君王應許相連，期待福音使命在歷史中結出廣泛果實。

下一步涉及這種廣泛順服何時出現。以賽亞描寫列國尋求主的訓誨，認識主的知識充滿全地（以賽亞書2:2-4；以賽亞書11:9-10）。後千年國說把相當程度的應驗放在基督再臨之前；前千年國說通常放在將來地上統治；其他讀者強調它在新創造中完成。應許相同，位置不同。

### 跟隨神國成長

耶穌把神國比作長成大樹的芥菜種，也比作發透整團麵的酵（馬太福音13:31-33）。後千年國讀者看見微小開端產生廣泛結果。保羅教導，基督必須掌權，直到一切仇敵都伏在腳下（哥林多前書15:25）。這些經文共同支持他們的期待：掌權的基督要藉福音改變列國。

麥子與稗子的比喻也必須考慮。兩者都存留到時代末了的收割（馬太福音13:24-30；馬太福音13:36-43）。後千年國說不必聲稱每個人都歸信，或所有罪在基督再臨前消失。它獨特的主張是門徒訓練在歷史中廣泛推進，不是無罪的新創造提前到來。

### 不忽略最後反叛和審判

啟示錄20:7-10把最後一次欺騙和敵對的爆發放在一千年之後。後千年國讀者保留福音興盛時期之後的最後反叛，隨後把普遍復活和審判放在基督再臨時，並把約翰福音5:28-29和馬太福音25:31-46與啟示錄20:11-15比較。

這個觀點必須解釋，它對福音廣泛結果的期待，怎樣與反覆警告苦難和背道相合（提摩太後書3:1-5；帖撒羅尼迦後書2:1-8）。後千年國解釋者對於哪些警告主要涉及早期危機，哪些描述最後爆發，也有分歧。它的時間線依賴這些上下文判斷；單憑成長的比喻，不能規定日曆或歸信者的比例。

## 被提：經文明說了什麼？

被提本身符合聖經。它相對於啟示錄各樣審判發生的時間，卻存在爭議。

保羅寫道：

> 「因為，召集令一發，天使長的呼聲一叫，上帝的號角一吹，主必親自從天降臨；那在基督裏死了的人必先復活，然後我們這些活著還存留的人必和他們一同被提到雲裏，在空中與主相會。這樣，我們就要和主永遠同在。」
>
> **帖撒羅尼迦前書 4:16-17**

保羅又說：

> 「我如今把一件奧祕的事告訴你們：我們不是都要睡覺，而是都要改變，就在一剎那，眨眼之間，號筒末次吹響的時候。因號筒要吹響，死人要復活成為不朽壞的，我們也要改變。」
>
> **哥林多前書 15:51-52**

「被提」背後的希臘語動詞是**harpazo**，意思是抓住或提上去。英語神學術語「rapture」最終經由這一概念的拉丁語翻譯而來。

爭論的不是信徒會不會被提去與基督相遇。聖經對此說得很清楚。爭論的是這件事會在**什麼時候**發生。

## 被提可能發生的位置

以下四種位置，是把同一聖經聚集事件與啟示錄異象相連的不同方案。

## 1. 災前被提論

**位置：** 第一印和末世患難期開始之前。

**簡短時間線:** 教會時代 -> 信徒在最後患難前被提 -> 印、號、碗 -> 基督有形再臨 -> 千禧年統治。

### 常用支持經文

- **帖撒羅尼迦前書 4:13-18**：信徒被提，與基督相遇。
- **帖撒羅尼迦前書 5:9**：信徒不是預定受忿怒。
- **約翰福音 14:1-3**：基督接祂的子民到自己那裡。
- **啟示錄 3:10**：應許保守非拉鐵非教會，**使其免受將臨到全世界的試煉時刻**。
- 「教會」一詞沒有用來稱呼啟示錄6-18章中地上的聖徒。

### 在啟示錄中被主張的位置

通常是第一印之前，即**啟示錄3章與4章之間**。

有些人把啟示錄4:1的「你上到這裡來」視為被提的象徵圖景。

### 主要難點

- 啟示錄4:1明文描述的是約翰進入異象，不是教會被移走。
- 啟示錄沒有直接說教會在第一印之前被提。
- 後面的異象中顯然仍有聖徒存在並受迫害。
- **帖撒羅尼迦後書 2:1-4**把基督的來臨和「我們到祂那裡聚集」，與離道反教及不法之人的顯露等事件聯繫起來。
- **馬太福音 24:29-31**把號聲和選民的聚集放在患難「以後立即」發生。

災前被提論者的回應是：被提有別於基督後來有形的再臨，並且教會有別於患難期間仍在地上的其他聖徒。

## 2. 災中被提論

**位置：** 最後時期的中點附近，常與啟示錄11章和第七號聯繫起來。

**簡短時間線:** 教會時代 -> 最後患難前半 -> 信徒在中點附近被提 -> 後續審判 -> 基督有形再臨 -> 千禧年統治。

### 常用支持聯繫

- **哥林多前書 15:52**：復活與改變發生在「末次號筒」時。
- **啟示錄 11:15**：第七枝，也是最後一枝號吹響。
- **啟示錄 11:12**：兩位見證人昇天。
- 啟示錄反覆使用四十二個月和一千二百六十日，表明可能有一個重要的中點結構。

### 主要難點

- 聖經從未明說保羅的「末次號筒」就是啟示錄的第七號。
- 兩位見證人昇天，明文所指的是這兩位見證人，不是整個教會。
- 啟示錄的各個四十二個月時期，並未全都明文排列為同一個七年期連續的兩個半段。

## 3. 災後被提論／基督有形再臨時

**位置：** 患難末期，與基督公開顯現相聯，緊接千禧年國度之前。

**簡短時間線:** 教會時代 -> 最後患難 -> 有形再臨、復活、信徒被提作為一組事件發生 -> 千禧年統治。

### 常用支持經文

**馬太福音 24:29-31**說：

- 患難「以後立即」
- 宇宙異象出現
- 人子駕雲顯現
- 大號吹響
- 天使聚集祂的選民

**帖撒羅尼迦前書 4:16-17**描述：

- 主從天降臨
- 號令
- 天使長的聲音
- 神的號
- 已死信徒復活
- 活著的信徒被提與祂相遇

**帖撒羅尼迦後書 2:1-4**把這些事一同提及：

- 「我們主耶穌基督的降臨」
- 「我們到祂那裡聚集」
- 離道反教先發生
- 不法的人顯露出來

**哥林多前書 15:23**把復活與基督的來臨聯繫起來。

**啟示錄19-20章**把基督有形地戰勝獸，直接放在那些被獸殺害的人復活之前，並把這稱為「第一次復活」。

### 主要難點

- 災前被提論者認為，這種看法把論及蒙救脫離忿怒的經文，與論及基督施行審判之再臨的經文混在一起。
- 啟示錄19章沒有明文使用「被提」這個詞。
- 災後被提論者必須解釋信徒如何在空中與基督相遇，並說明這場相遇與祂降臨、在地上作王之間的關係。

## 4. 神怒前被提論

**位置：** 在嚴酷的患難與迫害之後，通常認為在第六印之後，但在被理解為集中施行主之日忿怒的號災和碗災之前。

**簡短時間線:** 教會時代 -> 末世嚴酷逼迫 -> 天象 -> 基督顯現並聚集信徒 -> 集中的神聖忿怒 -> 千禧年統治。

### 常用支持聯繫

- **啟示錄 6:12-17**：第六印帶來宇宙異象，並宣告忿怒的大日已經來到。
- **馬太福音 24:29-31**：患難後出現宇宙異象，基督駕雲降臨，號筒吹響，選民被聚集。
- **啟示錄 7:9-17**：來自各國的大群人出現在寶座前，經文說他們從大患難中出來。
- **帖撒羅尼迦前書 5:9**：信徒不是預定受忿怒。

### 主要難點

- 先前各印也是羔羊親自揭開的，因此有人主張神的忿怒早在第六印之前就已運行。
- 啟示錄7章從未明說大群人的出現就是被提。
- 惡勢力造成的「患難」與神直接施行的「忿怒」之間如何精確劃分，屬於解釋問題。

## 對時間證據的謹慎綜合

啟示錄從未說「被提發生在第一印之前」、「發生在第六印」、「發生在第七號」，或「發生在啟示錄19章」。任何被提時間線都必須把啟示錄與耶穌的橄欖山講論和保羅書信協調起來。

有幾點觀察很難迴避：

1. **被提包含復活。** 在基督裡死去的人先復活，然後活著的信徒才被提（**帖撒羅尼迦前書 4:16-17**）。
2. **被提伴隨號聲。** **帖撒羅尼迦前書 4:16**和**哥林多前書 15:52**都這樣說。
3. **耶穌描述患難後伴隨號聲的選民聚集。** 參見**馬太福音 24:29-31**。
4. **保羅把基督來臨與我們到祂那裡聚集聯繫起來。** 參見**帖撒羅尼迦後書 2:1**。
5. **保羅說，離道反教和不法之人的顯露發生在「那日」之前。** 參見**帖撒羅尼迦後書 2:3-4**。
6. **啟示錄20章把一次復活放在獸被擊敗之後，並稱它為「第一次復活」。** 這句話與被主張在更早時發生的復活如何關聯，是核心解釋問題之一。
7. **信徒不是預定承受神的忿怒。** 參見**帖撒羅尼迦前書 5:9**。尚未解決的問題是：這意味著信徒從整個患難時期被移走，還是在其中蒙保守、不受神的忿怒。

基於這些經文，本研讀把**基督必再臨並聚集、復活祂子民的確定性**，與**把這場聚集放在啟示錄次序中某一位置的爭議性時間模型**區分開來。

## 總結

這份保留的總結描述未來主義前千禧年次序，不是上述所有立場共同接受的時間線。

啟示錄最清楚的末世次序是：

**審判藉著七印、七號和七碗逐步展開。獸與假先知興起並迫害聖徒。巴比倫傾倒。耶穌有形地再臨，擊敗獸和假先知。隨後撒但被捆綁。聖徒與基督一同作王一千年。一千年後，撒但被釋放，發動最後一次叛亂，繼而被扔進火湖。白色大寶座審判隨之而來。只有在這之後，神才創造新天新地，使新耶路撒冷降下；祂的子民在那裡永遠作王。**

被提是聖經所教導的事件，尤其見於**帖撒羅尼迦前書 4:16-17**和**哥林多前書 15:51-52**。它相對於啟示錄七印、七號和七碗的確切位置，並沒有在啟示錄中按編號明文標出。因此，應把它作為解釋問題來陳述，而不應說得好像經文中有一節明確宣告「被提就在這裡發生」。

## 藉聖經研讀各條時間線

從但以理書7:9-14、馬太福音24:29-31、帖撒羅尼迦前書4:13-18、哥林多前書15:20-28和啟示錄19:11-21:5開始。比較時間線以前，先把每段經文當作一個完整論證來讀。留意經文本身實際排列的事件，也留意由解釋補上的聯繫。

基督再臨呼召他的子民忠心服事、忍耐和盼望。耶穌藉著繼續工作的僕人教導預備（馬太福音24:42-51）。保羅吩咐哀傷的信徒以復活應許彼此鼓勵（帖撒羅尼迦前書4:18）。約翰呼召聖徒在忍耐中遵守上帝的命令，持守對耶穌的信仰（啟示錄14:12）。任何忠信的時間線解釋，都必須包括這些命令。
