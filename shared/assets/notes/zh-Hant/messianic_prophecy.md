# 彌賽亞預言圖譜

希伯來聖經中包含超過300條指向彌賽亞的預言。以下是主要的預言及其舊約出處和新約應驗。每一處經文引用都是確切的；請親自閱讀。

---

## 出生與淵源

- **由童貞女所生** 以賽亞書7:14 → 馬太福音1:22-23
- **生於伯利恆** 彌迦書5:2 → 馬太福音2:1-6
- **出自猶大支派** 創世記49:10 → 馬太福音1:2-3；希伯來書7:14
- **出自大衛的血脈** 撒母耳記下7:12-13；以賽亞書11:1 → 馬太福音1:1；羅馬書1:3
- **從埃及被召出** 何西阿書11:1 → 馬太福音2:14-15
- **有先驅開路** 以賽亞書40:3；瑪拉基書3:1 → 馬太福音3:1-3；馬可福音1:2-4

## 傳道事工

- **被聖靈恩膏** 以賽亞書61:1-2 → 路加福音4:18-21
- **在加利利傳道** 以賽亞書9:1-2 → 馬太福音4:13-16
- **像摩西一樣的先知** 申命記18:15-19 → 使徒行傳3:22-23；約翰福音6:14
- **用比喻教訓人** 詩篇78:2 → 馬太福音13:34-35
- **醫治瞎眼的、耳聾的、瘸腿的** 以賽亞書35:5-6 → 馬太福音11:4-6；約翰福音9:1-7
- **騎驢進入耶路撒冷** 撒迦利亞書9:9 → 馬太福音21:1-9；約翰福音12:14-16
- **成為絆腳石** 以賽亞書8:14；詩篇118:22 → 羅馬書9:32-33；彼得前書2:6-8

## 背叛與審判

- **被朋友出賣** 詩篇41:9 → 約翰福音13:18-21
- **被賣三十塊銀子** 撒迦利亞書11:12-13 → 馬太福音26:14-16；27:3-10
- **在控告者面前沉默** 以賽亞書53:7 → 馬太福音27:12-14；馬可福音14:60-61
- **被門徒離棄** 撒迦利亞書13:7 → 馬太福音26:31, 56
- **被假見證人控告** 詩篇35:11 → 馬太福音26:59-61

## 受難與釘十字架

- **手腳被扎** 詩篇22:16 → 約翰福音20:25-27；路加福音24:39-40
- **與罪犯同釘十字架** 以賽亞書53:12 → 馬可福音15:27-28；路加福音23:33
- **被嘲弄和譏誚** 詩篇22:7-8 → 馬太福音27:39-44；路加福音23:35
- **被給醋喝** 詩篇69:21 → 馬太福音27:34, 48；約翰福音19:28-30
- **衣服被分，拈鬮分贓** 詩篇22:18 → 約翰福音19:23-24
- **骨頭一根也不折斷** 詩篇34:20；出埃及記12:46 → 約翰福音19:33-36
- **肋旁被扎** 撒迦利亞書12:10 → 約翰福音19:34, 37
- **遍地黑暗** 阿摩司書8:9 → 馬太福音27:45
- **「我的神，我的神，為什麼離棄我？」** 詩篇22:1 → 馬太福音27:46

## 死亡與埋葬

- **作為代替性的贖罪祭而死** 以賽亞書53:4-6, 10-12 → 羅馬書5:6-8；哥林多後書5:21
- **葬在財主的墳墓裡** 以賽亞書53:9 → 馬太福音27:57-60

## 復活與升高

- **不被撇在陰間** 詩篇16:10 → 使徒行傳2:27-31；13:35-37
- **從死裡復活** 詩篇16:10；以賽亞書53:10-11 → 馬太福音28:5-6；使徒行傳2:32
- **升到神的右邊** 詩篇110:1 → 使徒行傳2:33-35；希伯來書1:3
- **照麥基洗德的等次永遠為祭司** 詩篇110:4 → 希伯來書5:5-6；6:20；7:17

## 受苦的僕人 以賽亞書53章

以賽亞書53章是最詳盡的彌賽亞預言。寫於釘十字架約700年前，它描述了：
- 一個被藐視、被人厭棄的人（53:3）→ 約翰福音1:10-11
- 擔當我們的憂患、背負我們的痛苦（53:4）→ 馬太福音8:17
- 因我們的過犯受傷（53:5）→ 羅馬書4:25
- 像羊羔被牽到宰殺之地，默然無聲（53:7）→ 使徒行傳8:32-35
- 與惡人同葬，與財主同墓（53:9）→ 馬太福音27:38, 57-60
- 他必看見後裔，並且延長年日（53:10）→ 復活

---

每一條預言都指向拿撒勒人耶穌。一個人僅憑偶然應驗其中八條預言的數學概率已被計算為10^17分之一（彼得·斯通納，*Science Speaks*）。祂應驗了全部。
