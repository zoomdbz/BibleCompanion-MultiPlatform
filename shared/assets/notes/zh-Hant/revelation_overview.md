# 啟示錄概覽

啟示錄（希臘語：*Apokalypsis* = 「揭開」）是唯一一卷向閱讀者許下祝福的書（啟示錄1:3）。它不是為了使人困惑；而是為了揭示。閱讀它的鑰匙在於認識到它在希伯來聖經、節期週期和第一世紀猶太慣用語中的深厚根基。

---

## 結構

啟示錄遵循1:19中給出的清晰大綱：
- **「你所看見的」** 復活基督的異象（第1章）
- **「現在的事」** 給七個教會的書信（第2-3章）
- **「將來必成的事」** 預言異象（第4-22章）

### 七的序列

| 序列 | 章節 | 主題 |
|------|------|------|
| 七教會 | 2-3 | 教會在各時代的狀況 |
| 七印 | 6-8:1 | 審判展開；唯有羔羊配揭開 |
| 七號 | 8-11 | 對地上不斷升級的警告 |
| 七碗 | 15-16 | 忿怒的最終傾倒 |

每個序列逐步加劇。七印是概略性的，七號影響三分之一，七碗則是全面性的。

---

## 節期的關聯

啟示錄浸透了節期的意象。整個預言敘事映射著秋季節期，正是那些仍等待最終應驗的節期：

### 吹角節 → 君王的歸來
- 啟示錄1:10 「當**主日**，我被聖靈感動，聽見在我後面有大聲音如**吹號**」
- 啟示錄4:1 「你上到這裡來，我要將以後必成的事指示你」，號聲召喚升上
- 帖撒羅尼迦前書4:16 「因為主必親自從天降臨，有呼叫的聲音和天使長的聲音，又有**神的號**吹響」
- 哥林多前書15:52 「就在**末次吹號**的時候。因號筒要響，死人要復活成為不朽壞的」

吹角節（約姆·特魯阿）是唯一在新月開始的節期，那一天**「沒有人知道那日子、那時辰」**，因為新月必須由兩個見證人目視確認。這不是說神在隱藏秘密；這是一個直接指向這個節期的希伯來慣用語。第一世紀的猶太聽眾聽到耶穌說「那日子、那時辰，沒有人知道」（馬太福音24:36），會立刻想到：約姆·特魯阿。

### 贖罪日 → 最終審判
- 啟示錄20:11-15 白色大寶座審判
- 撒迦利亞書12:10 「他們必仰望我，就是他們所扎的，必為我悲哀」
- 羅馬書11:26-27 「以色列全家都要得救……必有一位救主從錫安出來」
- 利未記16章 大祭司每年一次進入至聖所贖罪。耶穌一次永遠地進入了天上的至聖所（希伯來書9:11-12）。最終的應用仍在將來。

### 住棚節 → 神與人同住
- 啟示錄21:3 「看哪，**神的帳幕在人間**。祂要與人同住，他們要作祂的子民」
- 撒迦利亞書14:16-19 在彌賽亞的國度中，萬國都必上耶路撒冷守住棚節
- 約翰福音1:14 「道成了肉身，**住**（*eskēnōsen* = 『支搭帳幕』）在我們中間」

## 模式：第一次降臨與第二次降臨

前四個節期在第一次降臨中應驗。後三個等待在第二次降臨中應驗。它們之間的間隔，即「夏季收割」，對應教會時代。

| 節期 | 第一次降臨的應驗 | 第二次降臨的應驗 |
|------|----------------|----------------|
| 逾越節（尼散月14日） | 釘十字架 哥林多前書5:7 | |
| 除酵節（尼散月15日） | 埋葬 彼得前書2:22 | |
| 初熟節（尼散月16日） | 復活 哥林多前書15:20 | |
| 五旬節（西彎月6日） | 聖靈 使徒行傳2:1-4 | |
| *夏季間隔* | *教會時代* | *教會時代* |
| 吹角節（提斯利月1日） | | 再來 / 召聚 帖撒羅尼迦前書4:16 |
| 贖罪日（提斯利月10日） | | 以色列的悔改 羅馬書11:26 |
| 住棚節（提斯利月15日） | | 神與人同在 啟示錄21:3 |

春季節期**在確切的日子**應驗了。完全有理由期待秋季節期也將如此。

## 啟示錄中的希伯來慣用語

啟示錄大量取材於舊約意象和猶太文化背景。辨認這些能解開經文：

- **「沒有人知道那日子、那時辰」**（馬太福音24:36） 吹角節的慣用語（新月的不確定性）。見上文。
- **「像賊在夜間一樣」**（啟示錄3:3；帖撒羅尼迦前書5:2） 聖殿的總管（*ish har habayit*）夜間巡邏。若發現利未人守衛睡著，總管會點燃他的衣服。守衛必須「警醒」並「保守衣服」，因此啟示錄16:15說：「那警醒、**看守衣服**的有福了。」
- **「羔羊的婚筵」**（啟示錄19:7-9） 猶太婚俗：新郎在父家預備房間（約翰福音14:2-3），然後在未知的時候呼喊並吹號來接新婦（帖撒羅尼迦前書4:16）。七天的婚筵對應公開顯現前的七年。
- **「隱藏的嗎哪」**（啟示錄2:17） 藏在約櫃中的一罐嗎哪（希伯來書9:4）。據說耶利米在巴比倫毀城前藏起了約櫃（瑪加伯下2:4-8）。
- **「猶大支派中的獅子」**（啟示錄5:5） 創世記49:9-10
- **「受印的十四萬四千人」**（啟示錄7:4-8） 十二支派 × 12,000。無論是字面的還是象徵性的，這個數字反映了以色列的完全。

## 如何閱讀啟示錄

1. **把它當作第一世紀的猶太文本來讀**，不是21世紀的新聞資訊。其中的象徵來自舊約，不是現代地緣政治。
2. **以經解經。** 啟示錄中幾乎每個異象都能在希伯來聖經中找到出處: 但以理書、以西結書、撒迦利亞書、以賽亞書、出埃及記。
3. **謙卑地持守時間線。** 忠心的基督徒對七印、七號和七碗是順序的、重疊的還是循環的持不同意見。核心真理不是時間線；而是被殺的羔羊（啟示錄5:12）。
4. **留意節期。** 預言曆法是神的曆法。這一模式到目前為止完全準確。

啟示錄22:20 「證明這事的說：『是了，我必快來！』阿們！主耶穌啊，我願你來！」
