# ヨハネの黙示録 終末の時系列

この時系列は、ヨハネの黙示録の**素直な未来主義的・前千年王国的解釈**を基本的な枠組みとします。すなわち、ヨハネの黙示録19章でキリストが目に見える形で再臨し、その後サタンが縛られ、ヨハネの黙示録20章で聖徒たちがキリストとともに千年間支配し、その後サタンが解放され、最後の裁きが続き、その後に初めてヨハネの黙示録21-22章が新しい天、新しい地、新しいエルサレムを描く、という解釈です。

ヨハネの黙示録には、幻、幕間、回想、説明的な場面があります。そのため、ヨハネが現代のストップウォッチのような時系列を示しているかのように、すべての章を扱うべきではありません。ヨハネの黙示録12章は明らかな例です。終末の迫害を描く前に、メシアの誕生と昇天までさかのぼっているからです。

黙示録は、幻、警告、裁き、キリストの勝利、復活、最後の裁き、新しい創造を語ります。しかし、すべての読者が認める一枚の総合年表を示すわけではありません。このノートで**明記**とは、その箇所が問題の出来事または内容を述べていることを意味します。別々の幻を結び、日付を割り当て、順に起こるか重なるかを決める年表は、その読み方が自然であっても**総合的な解釈**です。

「黙示的」とは、幻と象徴を用いる黙示録の預言的な文学形式を表します。外典文学を意味せず、その約束の現実性を否定する言葉でもありません。

### 確信度の表示

- **明記：** 本文が出来事または順序を直接述べている。
- **順序からの推論：** ヨハネの幻の流れから自然に導かれる順序だが、本文は暦上の日付を示していない。
- **解釈：** 位置づけや象徴についてキリスト者の見解が分かれている。

## 解釈のアプローチ

黙示録が引き継ぐ聖書の箇所とともに、この書を読んでください。ダニエルは獣、天の法廷、支配を受ける人の子を見ます。ヨハネは、獣とキリストの勝利の幻の中で、それらの主題を展開します（ダニエル7:1-14、黙示録13:1-7、黙示録19:11-21）。エゼキエルは神の住まいと命を与える川を見ます。黙示録は、神が御自分の民とともに住み、命の川が流れる場面で終わります（エゼキエル47:1-12、黙示録21:3、黙示録22:1-5）。出来事を年表に割り当てる前に、これらのつながりから像の意味を学ぶ必要があります。

以下の年表は、別々の三つの問いによって形づくられます。解釈のアプローチは、幻がどの時代を描くかを問います。千年王国の見解は、千年とキリストの再臨がどう関係するかを問います。携挙の時期は、信者がいつよみがえり、主に会うかを問います。一つを選んでも、残り二つが自動的に決まるわけではありません。どの見解も、キリストが実際に戻られること、復活、裁き、新しい創造を説明しなければなりません（使徒1:9-11、ヨハネ5:28-29、黙示録20:11-21:5）。

### 未来主義: 幻は最後の危機へ進む

未来主義は、黙示録4-22章の多くを、将来のキリストの再臨を取り巻く出来事に置きます。最も強い根拠は、ヨハネが描く結末にあります。獣の敗北、聖徒の復活、サタンの最後の滅び、死のない創造です（黙示録19:19-21、黙示録20:4-10、黙示録21:1-4）。これらの約束は、七つの教会が置かれていた当時の状況を超えています。

この枠組みは、ダニエルが語る最後の苦難を、荒らす忌まわしいものと大患難についてのイエスの警告に結びつけます（ダニエル12:1-3、マタイ24:15-31）。獣による迫害と限られた権威も、これらの箇所とともに読みます（黙示録13:5-10）。そのため幻は未来に焦点を置きますが、ヨハネの最初の読者への警告も失いません。キリストはすでに、妥協を退け、迫害を耐え忍ぶよう七つの教会に求めておられました（黙示録2:10、黙示録2:20-25）。

**年代表:** 歴史上の七つの教会と現在の忍耐 -> 最後の危機 -> キリストの勝利 -> 復活、裁き、完成した神の国。未来主義的前千年王国説は、最後の裁きの前に千年統治を置きます。詳しい順序は以下に示します。

### 部分的過去主義: 近い裁きと将来の完成

部分的過去主義は、黙示録が実在の教会に宛てられ、時が近いと述べることから始めます（黙示録1:1-4、黙示録22:6-10）。裁きの言葉の多くを、一世紀の争いに結びつけます。エルサレム、その包囲、その世代に関するイエスの警告が重要な比較対象です（ルカ21:20-24、マタイ24:34）。エルサレムの陥落を重視する人も、ローマとその迫害を重視する人もいます。その同定には、聖書箇所だけでなく歴史的な論証も必要です。

このアプローチでは、過去の裁きを、最後の身体的復活と同一視せず、キリストの権威を示す出来事として読むことができます。黙示録自体が、歴史の中の裁きと、死の終わりおよび最後の裁きを区別します（黙示録18:1-24、黙示録20:11-21:4）。ここで扱う部分的過去主義は、使徒1:11が約束するイエスの身体的再臨をなお将来に期待します。将来の約束がすべてすでに成就したとは考えません。

**年代表:** 一世紀の迫害と裁き -> 継続する福音宣教とキリストの統治 -> 将来の身体的再臨、復活、最後の裁き -> 新しい創造。このアプローチは、無千年王国説または後千年王国説と組み合わされることがよくあります。

### 歴史主義: 教会史を貫く長い系列

歴史主義は、幻を使徒時代からキリストの再臨へ向かう教会の争いの長い記述として読みます。ダニエルが描く連続する王国が、その型を与えます。預言の幻は、神の最後の勝利に至るまで、複数の地上の権力をまたぐことができます（ダニエル2:31-45、ダニエル7:17-27）。黙示録も、争い、忍耐、キリストの統治を通って進みます（黙示録1:9、黙示録13:10、黙示録20:4）。

難しいのは、特定の封印、ラッパ、獣を、後代の制度や出来事と同定する段階です。黙示録は、中世や近代の名称一覧を示しません。歴史主義の計算の中には、民数記14:34とエゼキエル4:6を比較し、一日を一年とする原則を用いるものがあります。それらの箇所では、特定のしるしや裁きについて神が換算を明示します。それを別の箇所に適用するには、その箇所の文脈からの論証が必要です。

**年代表:** 使徒時代の教会 -> 連続する歴史上の争いと裁き -> キリストの最後の勝利 -> 復活、裁き、新しい創造。途中の出来事の割り当ては歴史主義の年表ごとに異なります。共通する主張は、教会史全体を長く見渡すという点です。

### 理想主義: キリストの統治のもとで繰り返される争い

理想主義の読み方は、あらゆる時代の信者が直面する型を重視します。強制的な権力、偽りの宗教、腐敗した富、忠実な証し、神の裁きです。ヨハネ自身の状況にも、患難、御国、忍耐が一緒に現れます（黙示録1:9）。七つの教会は、獣とバビロンの幻が展開する前から、苦しみと妥協への圧力に直面していました（黙示録2:9-10、黙示録2:13-16、黙示録18:3-5）。

このアプローチなら、新しい支配者が現れるたびに最後の獣と決めつけず、幻を後代の信者への教えとして読むことができます。繰り返す型が、最後には歴史上の決定的な頂点に達することもできます。黙示録の終わりは、勝利と敗北の終わりなき循環ではなく、悪の実際の滅びと、神が御自分の民とともに住まわれることです（黙示録20:10、黙示録21:1-5）。

**年代表:** キリストの勝利と教会の証し -> 繰り返す迫害、誘惑、裁き -> 最後の対決と再臨 -> 新しい創造。理想主義は、将来の最後の危機および千年を現在の時代とする理解と組み合わされることがよくあります。

## 未来主義的前千年王国説

### 全体の流れ

**七つの教会 -> 御座の間 -> 小羊が巻物を受け取る -> 七つの封印 -> 七つのラッパ -> 獣と偽預言者 -> 七つの鉢 -> バビロンの崩壊 -> キリストの目に見える再臨 -> 獣と偽預言者の敗北 -> サタンが縛られる -> 第一の復活と千年の支配 -> サタンの解放 -> 最後の反逆 -> サタンが火の池に投げ込まれる -> 大いなる白い御座の裁き -> 新しい天と新しい地 -> 新しいエルサレム -> 永遠の支配**

### 終末の裁きの前：ヨハネの黙示録1-5章

#### ヨハネの黙示録1章：復活したキリスト

ヨハネはイエス・キリストの黙示を受けます。七つの燭台の間におられる、栄光を受けた人の子を見ます。

**主要箇所：** ヨハネの黙示録 1:1-20。

#### ヨハネの黙示録2-3章：七つの教会

イエスは小アジアに実在した七つの教会に語りかけます。

1. エペソ
2. スミルナ
3. ペルガモ
4. テアティラ
5. サルディス
6. フィラデルフィア
7. ラオディキア

これらの手紙には、実際の歴史に即した教えと、「勝利を得る者」への繰り返しの約束があります。七つの教会が教会史の連続する七つの時代をも表すという説は一つの解釈であり、ヨハネの黙示録が明記していることではありません。

**主要箇所：** ヨハネの黙示録 2:1-3:22。

#### ヨハネの黙示録4章：御座の間

ヨハネは幻の中で天に上るよう招かれ、神の御座、二十四人の長老、四つの生き物、絶えることのない礼拝を見ます。

**携挙に関する重要な注記：** 患難前携挙説の教師たちは、**ヨハネの黙示録 4:1**の「ここに上れ」を、教会が携挙される姿とみなすことがあります。しかしこの節が直接描いているのは、天上の幻へと召された**ヨハネ**です。したがって、これは多く見積もっても予型的な証拠であり、携挙を明記した言葉ではありません。

#### ヨハネの黙示録5章：小羊と封印された巻物

神の御手には、七つの封印で封じられた巻物があります。それを開くにふさわしいのは、小羊であるイエス・キリストだけです。

イエスは次の方として示されます。

- ユダ部族の獅子
- ダビデの根
- ほふられた小羊

**主要箇所：** ヨハネの黙示録 5:1-14。

### 七つの封印

#### 第一の封印：白い馬、征服

**ヨハネの黙示録 6:1-2**

白い馬に乗る者が冠を与えられ、勝利を得るために出て行きます。

**解釈：** 未来主義者は一般に、この騎手を征服、欺きによる平和、または反キリストのような支配者と理解します。しかしヨハネの黙示録6章自体は、この騎手を「反キリスト」とも獣とも呼んでいません。

#### 第二の封印：赤い馬、戦争

**ヨハネの黙示録 6:3-4**

地上から平和が取り去られ、人々が互いに殺し合います。

#### 第三の封印：黒い馬、飢饉と欠乏

**ヨハネの黙示録 6:5-6**

食料が非常に高価になりますが、油とぶどう酒は損なわれません。

#### 第四の封印：青白い馬、死

**ヨハネの黙示録 6:7-8**

死とハデスは、剣、飢饉、疫病、野獣によって地上の四分の一を殺す権威を与えられます。

#### 第五の封印：殉教者が正義を求めて叫ぶ

**ヨハネの黙示録 6:9-11**

ヨハネは、神のことばと自分たちの証しのために殺された人々の魂を見ます。彼らは、同じように殺される仲間のしもべたちの数が満ちるまで、休んでいるよう告げられます。

これは、最後の裁きの前に迫害と殉教があることを示しています。

#### 第六の封印：宇宙的激変と恐怖

**ヨハネの黙示録 6:12-17**

次の出来事が含まれます。

- 大地震
- 太陽が暗くなる
- 月が血のように赤く見える
- 星が落ちる
- 空が巻物のように巻き去られる
- 山々と島々が動く
- 支配者と人々が神と小羊から隠れる

彼らはこう言います。

> 「御怒りの大いなる日が来たからだ。だれがそれに耐えられよう。」
>
> **ヨハネの黙示録 6:17**

この封印は携挙をめぐる議論で非常に重要です。その宇宙的なしるしが、**マタイ 24:29-31**にあるイエスの説明と似ているからです。

### ヨハネの黙示録7章：第七の封印の前の幕間

#### 印を押された十四万四千人

**ヨハネの黙示録 7:1-8**

イスラエルの諸部族から十四万四千人が印を押されます。記載された各部族から一万二千人ずつです。

本文はその数を二度示し（**ヨハネの黙示録 7:4; 14:1**）、各部族を名前で列挙しています（**ヨハネの黙示録 7:5-8**）。

#### 大群衆

**ヨハネの黙示録 7:9-17**

ヨハネは、あらゆる国民、部族、民族、言語から来た、数えきれない大群衆が神の御座と小羊の前にいるのを見ます。

彼らは大患難から出て来た者たちと説明されています。

**携挙との関係：** 御怒り前携挙説の解釈者は、この場面を、第六の封印の後、ラッパの裁きの前に信者が集められる証拠とみなすことがよくあります。しかしこの章は、「この大群衆はまさにこの時点で携挙された」と明記していないため、この同定は解釈にとどまります。

### 第七の封印：七つのラッパが始まる

**ヨハネの黙示録 8:1-6**

第七の封印が開かれると、

- 天が約半時間静まり返る
- 七人の御使いが七つのラッパを受け取る
- 聖徒たちの祈りが神の御前に立ち上る
- 祭壇の火が地に投げつけられる

素直に順を追って読むなら、七つのラッパは第七の封印から展開します。

### 七つのラッパ

#### 第一のラッパ：地と植物が打たれる

**ヨハネの黙示録 8:7**

血の混じった雹と火が地に降ります。地と木々の三分の一が焼かれ、すべての青草も焼かれます。

#### 第二のラッパ：海が打たれる

**ヨハネの黙示録 8:8-9**

火で燃える大きな山のようなものが海に投げ込まれます。

- 海の三分の一が血になる
- 海の生き物の三分の一が死ぬ
- 船の三分の一が破壊される

#### 第三のラッパ：苦よもぎ

**ヨハネの黙示録 8:10-11**

「苦よもぎ」と呼ばれる大きな星が、川と水の源の三分の一に落ちます。水は苦くなり、多くの人がその水によって死にます。

#### 第四のラッパ：天の光が暗くなる

**ヨハネの黙示録 8:12-13**

太陽、月、星の三分の一が打たれ、それぞれの光の三分の一が暗くなります。

続いて一羽の鷲が、最後の三つのラッパに対応する三つの災いが来ると告げます。

#### 第五のラッパ：第一の災い、底知れぬ所が開く

**ヨハネの黙示録 9:1-12**

落ちた星が底知れぬ所の鍵を受け取ります。いなごに似たものたちが出て来て、神の印を持たない人々を五か月の間苦しめます。

彼らの王は底知れぬ所の御使いで、ヘブライ語では**アバドン**、ギリシア語では**アポリュオン**と呼ばれます。

#### 第六のラッパ：第二の災い、ユーフラテスの軍勢

**ヨハネの黙示録 9:13-21**

ユーフラテス川につながれていた四人の御使いが解き放たれます。巨大な騎兵隊が描かれ、それに伴う災害によって人類の三分の一が殺されます。

生き残った人々はなおも、偶像礼拝、殺人、魔術、不品行、盗みを悔い改めようとしません。

### ヨハネの黙示録10章：小さな巻物

**ヨハネの黙示録 10:1-11**

力強い御使いが小さな巻物を持って現れます。ヨハネはそれを食べるよう命じられます。それは口には甘く、腹には苦いものでした。

そしてヨハネは、多くの民族、国民、言語、王たちについて、もう一度預言しなければならないと告げられます。

これは幕間であり、別の番号を持つラッパではありません。

### ヨハネの黙示録11章：神殿、二人の証人、第七のラッパ

#### 聖なる都と四十二か月

**ヨハネの黙示録 11:1-2**

異邦人は**四十二か月**の間、聖なる都を踏みにじります。

#### 二人の証人と千二百六十日

**ヨハネの黙示録 11:3-13**

二人の証人は**千二百六十日**の間預言します。

やがて彼らは底知れぬ所から上って来る獣に殺されます。その遺体は三日半さらされます。神が彼らをよみがえらせると、敵が見ている前で天に上ります。

その後、大地震が起こります。

#### 第七のラッパ：御国が宣言される

**ヨハネの黙示録 11:15-19**

第七の御使いがラッパを吹きます。

> 「この世の王国は、私たちの主と、そのキリストのものとなった。主は世々限りなく支配される。」
>
> **ヨハネの黙示録 11:15**

天の宣言は、神の支配、御怒り、裁き、報い、そして地を滅ぼす者たちの滅びについて語ります。

**患難期中携挙説との関係：** **コリント人への第一の手紙 15:52**にあるパウロの「最後のラッパ」を、ヨハネの黙示録の第七のラッパと同一視し、携挙をここに置く解釈者もいます。しかしヨハネの黙示録は、二つのラッパが同じものだと明記していません。したがって、これは解釈による結びつけです。

### ヨハネの黙示録12章：女、メシア、竜

ヨハネの黙示録12章は、この書を章ごとに硬直したストップウォッチのように読むことができない理由を示します。

幻には次のものが含まれます。

- 太陽をまとった女
- 女が産む子を食い尽くそうと待ち構える竜
- 諸国民を治めることになる男の子の誕生
- その子が神の御座へ引き上げられること
- 女が**千二百六十日**の間、荒野へ逃れること
- 天での戦い
- ミカエルとその御使いたちが竜を打ち破ること
- サタンが投げ落とされること

素直に順を追って読むなら、完全に現れた千年王国は**まだ到来していません**。ヨハネの黙示録はそれを、キリストの再臨における獣と偽預言者の目に見える敗北の後、サタンの最後の解放の前に置いているからです。

### ヨハネの黙示録は七年間の患難を教えているか

ヨハネの黙示録は、約三年半に相当する期間を繰り返し示します。

- **四十二か月**：ヨハネの黙示録 11:2
- **千二百六十日**：ヨハネの黙示録 11:3
- **千二百六十日**：ヨハネの黙示録 12:6
- **一時と二時と半時**：ヨハネの黙示録 12:14
- **四十二か月**：ヨハネの黙示録 13:5

一般的な未来主義的解釈は、これらの期間を**ダニエル 9:27**の最後の「一週」と組み合わせ、約三年半ずつの二つの期間に分かれた、終末の七年間を構成します。

これは妥当な調和のさせ方かもしれませんが、本文と解釈モデルは区別しなければなりません。

**ヨハネの黙示録自体には、「患難は七年間続く」という文は一度もありません。**

七年間という枠組みは、ヨハネの黙示録とダニエル書を組み合わせることによって生まれます。

## 未来主義的前千年王国説: 重なり合う幻

この見解は、黙示録19-22章の前千年王国的な結末を保ちながら、一部の幻が同じ期間を扱う可能性を認めます。ヨハネが幻を見た順序だけでは、その出来事がいつ始まるかが常に決まるとは考えません。黙示録自体が明確な例を示します。第七のラッパが御国を告げた後、黙示録12章はメシアの誕生と高挙へ戻ります（黙示録11:15-18、黙示録12:1-6）。

**短い年代表:** 教会時代 -> 重なりながら激しさを増す裁きの幻 -> キリストの目に見える再臨 -> 千年統治 -> サタンの最後の反乱 -> 最後の裁き -> 新しい創造。

### 繰り返される終点をたどる

第六の封印は天体の激変と怒りの大いなる日の告知に達します（黙示録6:12-17）。第七のラッパは、御国、怒り、裁き、神のしもべへの報いを告げます（黙示録11:15-19）。第七の鉢は完成を宣言し、かつてない地震とバビロンの裁きをもたらします（黙示録16:17-21）。重なり合う周期を見る読者は、各系列がまったく別の年数を加えると仮定せず、これらの終点を比較します。

出エジプトの災いも、裁きの言葉を説明します。血、暗闇、雹は、神がエジプトと対決された時を思い起こさせます（出エジプト7:17-21、出エジプト9:22-26、出エジプト10:21-23、黙示録8:7-9、黙示録16:3-10）。この共通の背景は、幻の類似を説明します。ただし、似ているだけでは二つの裁きが同時に起こる証明にはなりません。

### 期間は加算する前に比較する

黙示録11:2-3は、都が踏みにじられる四十二か月と、証しの千二百六十日を並べます。黙示録12:6と黙示録12:14は、女が守られる期間を、千二百六十日とも、一時と二時と半時とも表します。黙示録13:5は、獣に四十二か月の権威が与えられたと述べます。これらの表現は、ダニエル7:25とダニエル12:7との比較を促します。すべての期間を加えて、さらに長い総計にするよう命じてはいません。

重なりを提案するなら、そこに登場する人々、行動、期間、終点を特定する必要があります。女の保護と獣の迫害は、一つの争いの対立する両側を描くことができます。同時に起こるからといって、その違いが消えるわけではありません（黙示録12:13-17、黙示録13:5-10）。本文は出来事と期間を示します。それらをどう揃えるかは読者の総合です。

### 先取りと後の説明を区別する

御使いは黙示録14:8でバビロンの陥落を告げ、黙示録17-18章は後に、その性格と滅びを詳しく説明します。黙示録17:1は、遊女の裁きについての説明を始めることを明示します。鉢の後にその説明を読むからといって、バビロンが二度倒れる必要はありません。

したがって、未来主義の再現的な読み方は、すべての場面を別の時間枠へ押し込めずに、前へ進む流れを保ちます。また、携挙の時期を別個に検討する余地も残します。将来の千年王国を期待しながら、復活と集合を患難前、最後の危機の途中、またはキリストの公的な再臨時に置くことができます。その位置は、幻の重なり自体ではなく、関係する聖書箇所によって確立しなければなりません（マタイ24:29-31、テサロニケ人への手紙第一4:16-17）。

## 歴史的前千年王国説

歴史的前千年王国説は、キリストが将来の地上統治の前に再臨すると考えます。一般に、教会の復活と集合を、最後の患難後の公的な再臨に結びつけます。神の民への約束を保つために、教会が何年も前に取り去られることを必要とはしません。

**短い年代表:** 現在の教会時代 -> 激しくなる患難と背教 -> 目に見える再臨、復活、信者の集合 -> 千年統治 -> 最後の反乱 -> 最後の裁き -> 新しい創造。

### 来臨と集合をともに読む

イエスは、患難の後に人の子が現れ、選ばれた者たちが集められると説明します（マタイ24:29-31）。パウロは、キリストが下られること、亡くなった信者の復活、生きている信者が彼らとともに集められることを説明します（テサロニケ人への手紙第一4:13-18）。後には、背教と不法の者についての同じ議論の中で、キリストの来臨と私たちが主のもとに集められることを扱います（テサロニケ人への手紙第二2:1-8）。歴史的前千年王国説は、これらを一つの決定的な来臨についての記述として結びつけます。

この希望は、信者がすべての苦しみから逃れることを必要としません。イエスは弟子たちに患難への備えをさせ、黙示録は獣の迫害のもとで聖徒たちに忍耐を求めます（ヨハネ16:33、黙示録13:10）。神の怒りから救われる約束は揺るぎません。この見解は、その約束と迫害を免れることを区別します（テサロニケ人への手紙第一5:9-10）。

### 二つの敗北の間にある統治を読む

黙示録19:19-21は獣と偽預言者の敗北を描きます。続く黙示録20:1-6は、サタンが縛られ、第一の復活にあずかる者たちが統治することを描きます。千年の後、サタンは別の反乱を集め、神がそれを滅ぼされます（黙示録20:7-10）。歴史的前千年王国説は、この進行を連続する出来事として読み、第一の復活を身体の復活と理解します。

パウロも関連する順序を示します。キリストの復活、キリストの来臨時に主に属する者たちがよみがえること、その後、主がすべての敵を打ち破って王国を父に渡される終わりです（コリント人への手紙第一15:23-28）。この箇所はキリストの勝利の統治を支持しますが、その間隔の長さは述べません。この総合では、黙示録20章が千年を示します。

### 約束全体を説明する

前千年王国説の読者は、この将来の統治を、諸国民の間の正義を描きながら、死がまだ最終的に廃止されていない状態を示す箇所と結びつけます（イザヤ11:1-10、イザヤ65:20-25、ゼカリヤ14:16-19）。ほかのキリスト者は、それらの約束を現在の神の国または新しい創造を通して読みます。決定的な問いは、それらの箇所が黙示録20章とどう関係するかであって、神が約束を守られるかどうかではありません。黙示録21:4が最後の地平です。死そのものが終わります。

## 無千年王国説

無千年王国説は、千年をキリストの再臨後の別の地上時代ではなく、キリストが聖徒たちとともに治める現在の統治と理解します。実在する神の国と、将来の身体的復活の両方を認めます。その中心的な読み方では、黙示録20:1-6を、キリストの初臨と再臨の間の時代を別の角度から見た幻とします。

**短い年代表:** キリストの初臨と現在の天上統治 -> 教会時代の福音宣教、苦難、繰り返す争い -> 短い最後の反乱 -> 一度の目に見える再臨、全体の復活、最後の裁き -> 新しい創造。

### サタンの拘束をキリストの初臨とともに読む

黙示録20:3は、サタンを縛る目的を述べます。解放される時まで、諸国民を惑わさせないためです。イエスは御自身の働きを、強い人を縛ってからその家に入ることとして描きます（マタイ12:28-29）。十字架の前には、この世の支配者の裁きを告げ、御自身が上げられることによって人々を引き寄せると述べます（ヨハネ12:31-33）。無千年王国説の読者は、これらの箇所を諸国民への福音の前進と結びつけます。

そのため、拘束をサタンのあらゆる活動がなくなることではなく、その力への制限と理解します。使徒たちはなお信者に悪魔への警戒を命じるので、この区別は重要です（ペテロの手紙第一5:8-9）。前千年王国説の読者は、封印された底知れぬ所への監禁は、現在の世界に見られるものより強い拘束を描くと答えます（黙示録20:1-3）。どちらの読み方も、本文が述べる目的と幻の像が持つ強さを説明しなければなりません。

### 聖徒の命とキリストとの統治を読む

ヨハネは黙示録20:4で忠実な殉教者たちの魂を見ます。先にも、正しい裁きを待つ殉教者たちの魂を見ていました（黙示録6:9-11）。無千年王国説の一つの読み方は、彼らの命と統治を、現在天でキリストとともに生きることとします。別の説明は、信者が現在キリストの復活の命にあずかることを重視します（エペソ2:4-6、ヨハネ5:24-25）。同じ立場の中でも説明は異なりますが、どちらも後の身体的復活を否定しません。

主な難点は、彼らが生き返り、残りの死者は千年が終わるまで生き返らなかったというヨハネの言葉です（黙示録20:4-5）。前千年王国説は、同じ表現を両方とも身体的な意味に読みます。無千年王国説は、聖徒が現在死に勝利していることと最後の復活を区別し、天にいる魂の幻と、キリストにある命についての新約聖書の教えを通してこの箇所を読みます。

### 再臨を最後の完成として読む

イエスは、正しい者と悪い者の復活を、来たるべき一つの時の教えの中で結びつけます（ヨハネ5:28-29）。また、御自身が栄光のうちに来られることを諸国民の裁きと結びつけます（マタイ25:31-46）。ペテロは、主の日を裁き、および約束された新しい天と新しい地に結びつけます（ペテロの手紙第二3:10-13）。無千年王国説は、復活、裁き、新しい創造をキリストの再臨に置く時、これらの箇所を優先します。

この読み方は、黙示録20章を黙示録19章の後に始まる出来事の系列ではなく、再現として読むことに依存します。その場合、千年は現在の統治のために神が定めた完全な期間を表し、その後にサタンの短い解放と最後の敗北が続きます（黙示録20:3、黙示録20:7-10）。この見解の確信は、キリストの神の国の現実を否定することではなく、主の現在の統治と約束された再臨にあります。

## 後千年王国説

後千年王国説は、キリストの再臨前に、福音が諸国民の間に広い信仰と従順を生み出すと期待します。その期待を、現在の時代またはその中の後代の繁栄期と理解される千年王国に結びつけます。この希望は、キリストを離れた人類の自己改善ではなく、福音を通したキリストの働きに置かれます。

**短い年代表:** 現在の時代の福音宣教 -> 諸国民の広範な回心と王国の影響が長く続く時代 -> 最後の反乱 -> 目に見える再臨、復活、最後の裁き -> 新しい創造。

### 王の権威と命令から始める

復活したイエスは、天と地のすべての権威を宣言し、弟子たちをあらゆる国民を弟子とするために遣わされます（マタイ28:18-20）。詩篇2:7-9は諸国民を御子の相続財産として示します。詩篇72:8-11は、王の広い支配と諸国民の奉仕を描きます。後千年王国説は、この命令を王に関する約束と結び、福音宣教が歴史の中で広い実を結ぶと期待します。

次に問われるのは、その広い従順がいつ現れるかです。イザヤは、諸国民が主の教えを求め、主を知る知識が地に満ちることを描きます（イザヤ2:2-4、イザヤ11:9-10）。後千年王国説は、その相当な成就をキリストの再臨前に置きます。前千年王国説は一般に、将来の地上統治に置きます。ほかの読者は新しい創造での完成を重視します。約束は同じです。その位置づけが異なります。

### 神の国の成長をたどる

イエスは神の国を、大きな木へ育つからし種と、粉全体に働くパン種にたとえます（マタイ13:31-33）。後千年王国説の読者は、小さな始まりが広い結果を生むと考えます。パウロは、キリストがすべての敵を御自分の足の下に置くまで統治しなければならないと教えます（コリント人への手紙第一15:25）。これらの箇所を合わせ、統治するキリストが福音を通して諸国民を変えていくと期待します。

麦と毒麦のたとえにも注意が必要です。両方がこの時代の終わりの刈り入れまで残ります（マタイ13:24-30、マタイ13:36-43）。後千年王国説は、キリストの再臨前にすべての人が回心する、またはすべての罪が消えると主張する必要はありません。固有の主張は、罪のない新しい創造が早く到来することではなく、弟子化が歴史の中で広く前進することです。

### 最後の反乱と裁きを見失わない

黙示録20:7-10は、千年の後に、惑わしと反対が最後に噴き出すことを置きます。後千年王国説の読者は、福音が栄える時代の後にこの最後の反乱を保ちます。その後、ヨハネ5:28-29とマタイ25:31-46を黙示録20:11-15と比較し、全体の復活と裁きをキリストの再臨に置きます。

この見解は、福音が広く実を結ぶという期待と、苦難と背教について繰り返される警告をどう調和させるか説明しなければなりません（テモテへの手紙第二3:1-5、テサロニケ人への手紙第二2:1-8）。どの警告が主に過去の危機を扱い、どれが最後の反乱を描くかについて、後千年王国説の解釈者の間にも違いがあります。その年表は、それらの文脈判断に依存します。成長のたとえだけでは、暦も回心者の割合も示しません。

## 携挙：何が明記されているか

携挙そのものは聖書に基づく出来事です。ヨハネの黙示録の裁きとの時間的な関係については見解が分かれています。

パウロはこう書いています。

> 「主は、大号令と、天使の長の声と、神の召集ラッパの響きと共に天から下って来られます。その時、まず最初に復活して主にお会いできるのは、すでにこの世を去っているクリスチャンです。それから、なお生きて地上に残っている私たちが、いっしょに雲に包まれて引き上げられ、空中で主とお会いするのです。そして、いつまでも主と共に過ごすことになります。」
>
> **テサロニケ人への第一の手紙 4:16-17**

パウロはまたこう述べます。

> 「ここであなたがたに、驚くべき神の奥義を告げましょう。私たちはみな、新しい栄光の体をいただくのです。終わりのラッパが鳴り渡る時、一瞬のうちにそうなるのです。天からラッパの音が響くと、死んでいたすべてのクリスチャンは、たちまち朽ちない新しい体に復活します。次に、まだ生き残っている者もまた、一瞬にして新しい体に変わるのです。」
>
> **コリント人への第一の手紙 15:51-52**

「引き上げられ」に当たるギリシア語の動詞は**harpazo**で、つかみ取る、または引き上げるという意味です。英語の神学用語「rapture」は、最終的にはこの概念のラテン語訳に由来します。

論点は、信者が引き上げられてキリストに会うかどうかではありません。それは聖書に明白です。論点は、それが**いつ**起こるかです。

## 携挙が置かれ得る時点

以下の四つは、同じ聖書的な集合を黙示録の幻にどう位置づけるかについての異なる提案です。

## 1. 患難前携挙説

**位置：** 第一の封印と終末の患難期が始まる前。

**短い年代表:** 教会時代 -> 最後の患難前に信者が携挙される -> 封印、ラッパ、鉢 -> キリストの目に見える再臨 -> 千年統治。

### 一般的な根拠箇所

- **テサロニケ人への第一の手紙 4:13-18**：信者が引き上げられ、キリストに会う。
- **テサロニケ人への第一の手紙 5:9**：信者は御怒りに定められていない。
- **ヨハネ 14:1-3**：キリストがご自分の民をみもとに迎える。
- **ヨハネの黙示録 3:10**：フィラデルフィアの教会を、**全世界に来ようとしている試練の時から**守るという約束。
- 「教会」という語が、ヨハネの黙示録6-18章の地上の聖徒たちには使われていない。

### ヨハネの黙示録で提案される位置

通常は第一の封印の前、**ヨハネの黙示録3章と4章の間**です。

ヨハネの黙示録4:1の「ここに上れ」を、携挙を象徴する姿とみなす人もいます。

### 主な難点

- ヨハネの黙示録4:1が明記しているのは、教会が取り去られることではなく、ヨハネが幻に入ることです。
- ヨハネの黙示録は、教会が第一の封印の前に携挙されたとは直接述べていません。
- 後の幻にも聖徒たちが明らかに存在し、迫害されています。
- **テサロニケ人への第二の手紙 2:1-4**は、キリストの来臨と「私たちが御前に集められること」を、背教や不法の者の出現を含む出来事と結びつけています。
- **マタイ 24:29-31**は、ラッパと選ばれた者たちの集合を患難の「直後」に置いています。

患難前携挙説の解釈者は、携挙と後のキリストの目に見える再臨を区別し、教会と患難期に存在するほかの聖徒たちを区別することで答えます。

## 2. 患難期中携挙説

**位置：** 最後の期間の中間点付近。多くの場合、ヨハネの黙示録11章と第七のラッパに関連づけられる。

**短い年代表:** 教会時代 -> 最後の患難の前半 -> 中間点付近で信者が携挙される -> 後の裁き -> キリストの目に見える再臨 -> 千年統治。

### 一般的に示される関連

- **コリント人への第一の手紙 15:52**：復活と変化が「最後のラッパ」の時に起こる。
- **ヨハネの黙示録 11:15**：第七の、最後のラッパが鳴る。
- **ヨハネの黙示録 11:12**：二人の証人が天に上る。
- ヨハネの黙示録が四十二か月と千二百六十日を繰り返し用いており、重要な中間点の構造を示唆している。

### 主な難点

- パウロの「最後のラッパ」がヨハネの黙示録の第七のラッパであると、聖書は明記していません。
- 二人の証人の昇天は、教会全体ではなく、明確に二人の証人について述べています。
- ヨハネの黙示録の四十二か月の期間すべてが、一つの七年間の連続する前半と後半として明記されているわけではありません。

## 3. 患難後携挙説／キリストの目に見える再臨時

**位置：** 患難の終わり。キリストが公に現れる時に関連し、千年王国の直前。

**短い年代表:** 教会時代 -> 最後の患難 -> 目に見える再臨、復活、信者の携挙が一連の出来事として起こる -> 千年統治。

### 一般的な根拠箇所

**マタイ 24:29-31**は次のように述べます。

- 患難の「直後」
- 宇宙的なしるしが起こる
- 人の子が雲に乗って現れる
- 大きなラッパが鳴る
- 御使いたちが選ばれた者を集める

**テサロニケ人への第一の手紙 4:16-17**は次のことを描きます。

- 主が天から下って来る
- 号令
- 御使いのかしらの声
- 神のラッパ
- 死んだ信者の復活
- 生きている信者が引き上げられて主に会う

**テサロニケ人への第二の手紙 2:1-4**は次のことを一緒に語ります。

- 「私たちの主イエス・キリストの来臨」
- 「私たちが御前に集められること」
- まず背教が起こること
- 不法の者が現れること

**コリント人への第一の手紙 15:23**は、復活をキリストの来臨と結びつけます。

**ヨハネの黙示録19-20章**は、キリストが目に見える形で獣に勝利した直後に、獣によって殺された者たちが生き返る場面を置き、それを「第一の復活」と呼びます。

### 主な難点

- 患難前携挙説の解釈者は、この見解が、御怒りからの救出を述べる箇所とキリストの裁きのための再臨を述べる箇所を一つにしてしまうと主張します。
- ヨハネの黙示録19章は「引き上げられる」という表現を明記していません。
- 患難後携挙説の解釈者は、信者が空中でキリストに会うことと、その会見がキリストの降臨と地上での支配にどう関係するかを説明しなければなりません。

## 4. 御怒り前携挙説

**位置：** 激しい患難と迫害の後、多くの場合は第六の封印の後だが、主の日の御怒りが集中すると理解されるラッパと鉢の裁きの前。

**短い年代表:** 教会時代 -> 終末の激しい迫害 -> 天体のしるし -> キリストが現れ、信者を集める -> 集中的な神の怒り -> 千年統治。

### 一般的に示される関連

- **ヨハネの黙示録 6:12-17**：第六の封印で宇宙的なしるしが起こり、御怒りの大いなる日が来たと宣言される。
- **マタイ 24:29-31**：患難の後、宇宙的なしるしが現れ、キリストが雲に乗って来られ、ラッパが鳴り、選ばれた者たちが集められる。
- **ヨハネの黙示録 7:9-17**：あらゆる国民から来た大群衆が御座の前に現れ、大患難から出て来た者たちと呼ばれる。
- **テサロニケ人への第一の手紙 5:9**：信者は御怒りに定められていない。

### 主な難点

- 小羊ご自身がそれ以前の封印を開くため、第六の封印の前から神の御怒りがすでに働いていると論じる人もいます。
- ヨハネの黙示録7章は、大群衆の到着を携挙だと明記していません。
- 悪の勢力が引き起こす「患難」と、神が直接下す「御怒り」との正確な境界は、解釈によるものです。

## 時期を示す証拠の慎重な総合

ヨハネの黙示録は、「携挙は第一の封印の前に起こる」、「第六の封印で起こる」、「第七のラッパで起こる」、または「ヨハネの黙示録19章で起こる」とは述べていません。携挙の時系列を組み立てるには、ヨハネの黙示録を、イエスのオリーブ山での説教とパウロの手紙と調和させる必要があります。

避けることが難しい観察がいくつかあります。

1. **携挙には復活が伴う。** 生きている信者が引き上げられる前に、キリストにある死者がよみがえります（**テサロニケ人への第一の手紙 4:16-17**）。
2. **携挙にはラッパが伴う。** **テサロニケ人への第一の手紙 4:16**と**コリント人への第一の手紙 15:52**の両方がそう述べています。
3. **イエスは、患難後にラッパとともに選ばれた者たちが集められると述べる。** **マタイ 24:29-31**を参照してください。
4. **パウロはキリストの来臨と、私たちが御前に集められることを結びつける。** **テサロニケ人への第二の手紙 2:1**を参照してください。
5. **パウロは、背教と不法の者の出現が「その日」に先立つと述べる。** **テサロニケ人への第二の手紙 2:3-4**を参照してください。
6. **ヨハネの黙示録20章は復活を獣の敗北の後に置き、それを「第一の復活」と呼ぶ。** この表現が、それ以前に起こると提案される復活とどう関係するかは、中心的な解釈上の問題の一つです。
7. **信者は神の御怒りに定められていない。** **テサロニケ人への第一の手紙 5:9**を参照してください。未解決の問題は、これが患難期全体から取り去られることを意味するのか、その期間中に神の御怒りから守られることを意味するのか、という点です。

これらの聖句があるため、この学びでは、**キリストの再臨と、その民の集合・復活が確実であること**と、**その集合をヨハネの黙示録の流れのどこに置くかという、見解の分かれる時期のモデル**とを区別します。

## 要約

この保存された要約は未来主義的前千年王国説の順序を説明するもので、上記のすべての立場が共有する時系列ではありません。

ヨハネの黙示録が示す最も明確な終末の流れは次のとおりです。

**封印、ラッパ、鉢を通して裁きが展開します。獣と偽預言者が現れ、聖徒たちを迫害します。バビロンが倒れます。イエスが目に見える形で再臨し、獣と偽預言者を打ち破ります。その後、サタンが縛られます。聖徒たちはキリストとともに千年間支配します。千年の後にサタンは解放され、最後の反逆を率い、火の池に投げ込まれます。大いなる白い御座の裁きが続きます。その後に初めて、神は新しい天と新しい地を創造し、新しいエルサレムを下らせ、そこで神の民は永遠に支配します。**

携挙は、特に**テサロニケ人への第一の手紙 4:16-17**と**コリント人への第一の手紙 15:51-52**に記された聖書的な出来事です。ヨハネの黙示録の封印、ラッパ、鉢との正確な位置関係は、ヨハネの黙示録の中で番号を付けて明記されていません。したがって、「携挙はここで起こる」と本文が述べる節があるかのようにではなく、解釈上の問題として提示すべきです。

## 聖書から年表を学ぶ

ダニエル7:9-14、マタイ24:29-31、テサロニケ人への手紙第一4:13-18、コリント人への手紙第一15:20-28、黙示録19:11-21:5から始めてください。年表を比較する前に、それぞれの箇所を一つのまとまった論証として読んでください。その箇所が実際に順序づける出来事と、解釈によって加えられたつながりを区別してください。

キリストの再臨は、御自分の民を忠実な奉仕、忍耐、希望へ招きます。イエスは、働きを続けるしもべたちを通して備えを教えます（マタイ24:42-51）。パウロは、悲しむ信者たちに、復活の約束によって互いに励まし合うよう命じます（テサロニケ人への手紙第一4:18）。ヨハネは、耐え忍びながら神の戒めとイエスへの信仰を守るよう聖徒たちに呼びかけます（黙示録14:12）。どの忠実な年表の読み方にも、これらの命令が含まれなければなりません。
