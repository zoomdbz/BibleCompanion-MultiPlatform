# イエスの神性

聖書はこの二つの点について明確です。本書は関連する参照とともに、二つのセクションで明らかにします。

1) イエスは神の子である  

そして  

2) イエスは神である  

*注: 本書の翻訳注は、原典言語（ヘブライ語・ギリシア語・アラム語）が、イエスの神的アイデンティティに直接関わる用語をどのように表現しているかを示します。これは日本語からヘブライ語等への翻訳ではなく、イエスの神性を裏づける最古層の言語的証拠への参照です。*  

---

## 1) 神の子

**福音書の中心的な箇所**  
-  マタイ 3:17；マルコ 1:11；ルカ 3:22 : バプテスマの場で父がイエスを明らかにする。  

-  マタイ 17:5；マルコ 9:7；ルカ 9:35 : 変貌。声が彼を愛する子と呼ぶ。  

-  マタイ 4:3-6；ルカ 4:3-9 : 試み。サタンが挑む：「もしあなたが神の子なら」。  

-  マタイ 8:29；マルコ 3:11；ルカ 4:41 : 悪霊たちは彼を神の子と認める。  

-  マタイ 14:33 : 弟子たちは礼拝して言う：「まことにあなたは神の子です」。  

-  マタイ 16:16 : ペテロ：「あなたはキリスト、生ける神の子です」。  

-  マタイ 26:63–64；マルコ 14:61–62；ルカ 22:70 : 彼の神の子としての身分を問う裁判の場面。  

-  ヨハネ 1:34-49 : バプテスマのヨハネとナタナエルは彼を神の子と呼ぶ。  

-  ヨハネ 3:16–18; 35–36 : 父によって遣わされた独り子。  

-  ヨハネ 5:25 : 死者は神の子の声を聞く。  

-  ヨハネ 10:36 : 父が彼を聖別し神の子として遣わしたとイエスは言う。  

-  ヨハネ 11:4; 11:27 : ラザロの出来事が神の子に結びつき、マルタが告白する。  

-  ヨハネ 19:7 : 自分を神の子としたという訴え。  

-  ヨハネ 20:31 : 目的記述：イエスがキリスト、神の子であると信じさせるため。  


**旧約の基盤と王的・メシア的な参照**  

-  サムエル記下 7:12–14 : ダビデ契約；王の子という言語。  

  - ヘブライ語: בֵּן (*ben*)  
  - ギリシア語（LXX）: υἱός (*huios*)  
  - アラム語: בַּר (*bar*)  
  - **日本語:** 「子」  
  - *背景: ダビデ王は神の子と呼ばれる；これはイエスに真の神の子として適用される。*  

-  詩編 2:7 : 「あなたはわたしの子、きょうわたしがあなたを生んだ」。  

  - ヘブライ語: בְּנִי אַתָּה (*beni attah*)  
  - ギリシア語（LXX）: υἱός μου εἶ σύ (*huios mou ei sy*)  
  - アラム語: אַתְּ בְּרִי (*att bri*)  
  - **日本語:** 「わたしの子」  
  - *背景: 即位の詩。メシアを神の子として示す。*  

-  詩編 110:1 : 「主はわたしの主に言われた」。  

  - ヘブライ語: לַאדֹנִי (*la’adoni*)  
  - ギリシア語（LXX）: τῷ κυρίῳ μου (*tō kyriō mou*)  
  - アラム語: לְמָרִי (*l’mari*)  
  - **日本語:** 「わたしの主」  
  - *背景: 第二の『主』が神的権威をもって着座する；イエスはこれを自らに適用する。*  

-  イザヤ 9:6 : 神的称号を持つ子、ダビデの王座。  

  - ヘブライ語: אֵל גִּבּוֹר (*El Gibbor*)  
  - ギリシア語（LXX）: ἄγγελος μεγάλης βουλῆς (*angelos megalēs boulēs*)  
  - アラム語: אֱלָהּ גִּבָּר (*elah gibbar*)  
  - **日本語:** 「力ある神」  
  - *背景: ダビデの王座に就く神的な子に関する預言；称号は神だけに属する。*  

-  ダニエル 7:13 : 「人の子のような者」が支配権を受ける。  

  - ヘブライ語/アラム語: כְּבַר אֱנָשׁ (*ke-bar enash*)  
  - ギリシア語（LXX/OG）: ὡς υἱὸς ἀνθρώπου (*hōs huios anthrōpou*)  
  - アラム語（原文）: בַּר אֱנָשׁ (*bar enash*)  
  - **日本語:** 「人の子」  
  - *背景: 天的な御方が永遠の支配を受ける幻；イエスはこの称号を自らに用いた。*  

**福音書以外の新約の参照**  
-  ローマ 1:3–4 : 復活により力ある神の子と宣言された。  

-  ガラテヤ 4:4–6 : 神は御子を遣わし、御子の霊を与えられた。  

-  ヘブライ 1:1–5 : 御子は御使いたちにまさる；詩編2がイエスに適用。  

-  1 ヨハネ 4:9–15; 5:5; 5:10–13 : イエスが神の子であるとの告白は命を与える。  


**読者への注**  
-  「神の子」は王的・メシア的枠組みにおいて、神の支配を担う油注がれた王を意味する。福音書では、この称号は比喩を越え、父のみ声、イエスの固有の関係、そして神的わざによって、神との一体性を示す称号へと高められる。

## 2) 神である

**イエスによる／イエスについての直接的な同一性と一致の宣言**  

-  ヨハネ 1:1 : 「言は神であった」。  

  - ヘブライ語: דְּבַר יְהוָה (*d’var YHWH*)  
  - ギリシア語: λόγος (*logos*)  
  - アラム語: מֵימְרָא (*memra*)  
  - **日本語:** 「言（ことば）」  
  - *背景: ロゴス（言）は神として示され、イエスにおいて肉となった。*  

-  ヨハネ 8:58 : 「アブラハムが生まれる前から、わたしはある」。  

  - ヘブライ語（出 3:14）: אֶהְיֶה אֲשֶׁר אֶהְיֶה (*ehyeh asher ehyeh*)  
  - ギリシア語: ἐγώ εἰμι (*egō eimi*)  
  - アラム語: אֲנָא הוּא דַהֲוֵית (*ana hu dahaveit*)  
  - **日本語:** 「わたしはある」  
  - *背景: 出エジプト記の神の自己啓示名を、イエスはみずからに適用する。*  

-  ヨハネ 10:30 : 「父とわたしは一つである」。  

  - ヘブライ語: אֶחָד (*echad*)  
  - ギリシア語: ἕν (*hen*)  
  - アラム語: חַד (*chad*)  
  - **日本語:** 「一つ」  
  - *背景: 父との一致の宣言；聞く者たちは冒涜だとして訴える。*  

-  ヨハネ 20:28 : 「わたしの主、わたしの神」。  

  - ヘブライ語: אֲדֹנִי וֵאלֹהַי (*adonai v’elohai*)  
  - ギリシア語: ὁ κύριός μου καὶ ὁ θεός μου (*ho kurios mou kai ho theos mou*)  
  - アラム語: מָרִי וֵאלָהִי (*mari v’elahi*)  
  - **日本語:** 「わたしの主、わたしの神」  
  - *背景: トマスは復活のイエスを明確に主・神と告白する。*  

**神性を示す特権と行為**  
-  マルコ 2:5–12；マタイ 9:2–8；ルカ 5:20–26 : 罪の赦し。律法学者たちは「神だけが赦せる」と言う。  

-  マタイ 14:25–33；マルコ 6:48–51 : 海の上を歩く；弟子たちは礼拝する。  

-  マルコ 4:39–41；マタイ 8:26–27；ルカ 8:24–25 : 嵐を静める；詩編 107:29 の反響。  


**三位一体の枠組み**  
-  マタイ 28:18–20 : 「父と子と聖霊の**名**によってバプテスマを授けよ」。  

  - ヘブライ語: בְּשֵׁם (*b’shem*)  
  - ギリシア語: ὄνομα (*onoma*)  
  - アラム語: שְׁמָא (*shema*)  
  - **日本語:** 「名（単数）」  
  - *背景: 父・子・霊により共有される一つの名: 神的な一致。*  

-  ヨハネ 14–16 : イエスは助け主を遣わし、父・子・霊は一つの使命において働く。  


**旧約における神の名とアイデンティティ**  
-  出エジプト記 3:14 : 「わたしは**ある**という者である」。  

  - ヘブライ語: אֶהְיֶה אֲשֶׁר אֶהְיֶה (*ehyeh asher ehyeh*)  
  - ギリシア語（LXX）: ἐγώ εἰμι ὁ ὤν (*egō eimi ho ōn*)  
  - アラム語: אֲנָא הוּא (*ana hu*)  
  - **日本語:** 「わたしはある」  
  - *背景: 神の自己同定；ヨハネ 8:58 や黙示録で反響。*  

-  申命記 32:39；イザヤ 41:4; 43:10–11; 44:6; 48:12 : 神は「初めであり終わりである」；黙示録 1:17–18 に反映。  


**福音書以外の新約の参照**  
-  ローマ 9:5 : すべての上におられるキリスト、永遠にほむべき神。  

-  ピリピ 2:6–11 : 神の姿におられた方；「すべてのひざがかがむ」；イザヤ 45 の響き。  

-  コロサイ 1:15–20; 2:9 : 神性の満ち満ちたものがからだに宿る；創造者にして保持者。  

-  テトス 2:13 : 「わたしたちの偉大な神であり救い主であるイエス・キリスト」。  

-  ヘブライ 1:3；ヘブライ 1:8–12 : 御子は神の栄光の輝き；神的詩篇が御子に適用される。  

-  黙示録 1:8; 1:17–18; 22:13 : 「アルファでありオメガ」；「最初であり最後」；死んで生きておられる方。  


**読者への注**  
-  福音書においてイエスは、父との一致を宣言するだけでなく、罪の赦し・被造界への主権・神の名と栄光の共有・礼拝の受容といった唯一神の特権を行使する。使徒たちはその後、彼を曖昧さのない神的称号で語る。

### 主要ポイント

-  最短の一致宣言 ヨハネ 10:30。  

-  イエスを見ることは父を見ること ヨハネ 14:9–11。  

-  「わたしはある」の主張 ヨハネ 8:58 と 出エジプト記 3:14。  

-  神的行為に結びつく礼拝の場面 マタイ 14:33；マルコ 4:41。  

-  王的な「子」から神的な「子」へ導く旧約の基盤 サム下 7；詩 2；詩 110；イザ 9；ダニ 7。  

-  福音書外の新約の総合 ピリピ 2；コロサイ 1–2；ヘブライ 1；黙示録 1；テトス 2:13。

# イエスの見捨てられた叫び

イエスの神性を理解するうえで重要な瞬間は、十字架からの叫びです。*「わが神、わが神、なぜわたしをお見捨てになったのですか」* (マタイ 27:46) (マルコ 15:34)。一見するとこれは弱さや神からの断絶のように聞こえますが、実際には彼の完全な人間性と神の使命の両方を明らかにしています。詩篇22篇 (詩篇 22:1) の冒頭を引用することで、イエスは詩篇全体に注意を向けさせました : 深い嘆きから始まり、勝利と世界的な礼拝で終わる箇所です。この叫びは神性の喪失ではなく、人の罪と裁きの経験に完全に入り込み、それを贖うための神の子の行為です。

---

イエスが叫んだとき *「わが神、わが神、なぜわたしをお見捨てになったのですか」* (マタイ 27:46) (マルコ 15:34)、彼は**詩篇22篇の冒頭を引用していた** (詩篇 22:1)。ユダヤの習慣では、冒頭の一行を口にすることで、聞き手は**詩篇全体**を思い起こしました。

---

### 詩篇22篇が示すこと

- **嘆きから始まる**: 詩人は捨てられたと感じる。

- **十字架の場面を描く**: あざけり、手足が刺し貫かれ、衣服が分けられる。

- **勝利で終わる**: 神が救い、国々が礼拝し、詩篇は *「成し遂げられた」* (詩篇 22:31) (イエスの言葉 *「成し遂げられた」* (ヨハネ 19:30) に類似) で締めくくられる。

---

### 「見捨てられた」の意味

- **イエスは人間として神からの距離を本当に感じた。** 彼は私たちの罪と呪いの重荷をすべて背負った。

- **三位一体の断絶ではない。** 父と子が存在において分かたれたことは一度もない。イエスはなおも父に信頼し、最後の言葉は *「父よ、わたしの霊を御手にゆだねます」* であった (ルカ 23:46)。

- **契約の裁きを担った。** 十字架で彼は罪の刑罰を負った (ガラテヤ 3:13) (コリント第二 5:21)。この「見捨てられ」は司法的なものであり、関係的なものではない。

---

### なぜ彼はそう言ったのか

- **私たちの苦しみに共感するため**: すべての捨てられた心の祈りをささげた。

- **詩篇22篇を指し示すため**: 彼の死が聖書の成就であることを示した。

- **私たちに教えるため**: 嘆きは不信仰ではない : それは希望と勝利への入口である。

---

### 重要な洞察

イエスはその神性において見捨てられたのではない。彼は**私たちの見捨てられた感覚に入り込むことを選ばれた**。それを担い、贖い、私たちを勝利へ導くためである。彼の見捨てられた叫びは、私たちの最も暗い瞬間から神の救いの力への橋となる。

## イエスと預言の成就
イエスは一つや二つの預言を成就しただけではありません。学者たちは旧約聖書において**300以上のメシア預言**がイエスを指し示していると数えています。これには、誕生、家系、宣教、裏切り、十字架刑、復活、昇天が含まれます。

- 統計的に見ると、一人の人間がわずか8つの預言を成就する確率は約 **10^17分の1**（100京分の1）です。

- 48の預言を成就する確率は約 **10^157分の1** であり、偶然では事実上不可能です。

- イエスは何百もの預言を成就されました。数学的に見ても、イエスこそ唯一のメシアであることは圧倒的です。

例としては以下が含まれます：

- ベツレヘムで生まれる（ミカ書 5:2；マタイ 2:1で成就）。

- 処女から生まれる（イザヤ書 7:14；ルカ 1:26–35で成就）。

- 30枚の銀貨で裏切られる（ゼカリヤ書 11:12–13；マタイ 26:15で成就）。

- 手足が刺し貫かれ、衣服がくじで分けられる（詩篇 22:16–18；ヨハネ 19:23–24で成就）。

- 神殿が破壊される前に殺される（ダニエル書 9:26；西暦30–33年に成就）。

- 三日目によみがえる（詩篇 16:10；ホセア書 6:2；ルカ 24:46で成就）。

**この確率をイメージするために：**

- 一度だけ国の宝くじに当たる確率は約3億分の1です。イエスが8つの預言を成就するのは、その宝くじに **50万回以上連続で当たる** のと同じです。

- 一生のうちに雷に打たれる確率は約15,000分の1です。預言の成就の確率はそれよりも何兆倍も稀です。

- ピーター・ストーナーは次のように説明しました。テキサス州全体を銀貨で60センチの深さに覆い、そのうち一枚に印を付け、目隠しをした人を歩かせます。その人が最初の一回で印のついたコインを拾う確率が、わずか8つの預言を成就する確率と同じです。

- さらに進めると、48の預言を成就するのは、**地球上のすべての浜辺の砂粒を数え、一粒に印を付け、目隠しをして一度でそれを見つける** ようなものです。

- 300以上の預言を成就することは？ 確率は指数関数的に大きくなり、人間の言語や数学では表現できないほどの不可能性となり、神のご計画によるとしか説明できません。

数学的にも、歴史的にも、そして預言的にも、イエスこそ唯一の成就です。
