# 弥赛亚预言图谱

希伯来圣经中包含超过300条指向弥赛亚的预言。以下是主要的预言及其旧约出处和新约应验。每一处经文引用都是确切的: 请亲自阅读。

---

## 出生与渊源

- **由童贞女所生**: 以赛亚书7:14 → 马太福音1:22-23
- **生于伯利恒**: 弥迦书5:2 → 马太福音2:1-6
- **出自犹大支派**: 创世记49:10 → 马太福音1:2-3；希伯来书7:14
- **出自大卫的血脉**: 撒母耳记下7:12-13；以赛亚书11:1 → 马太福音1:1；罗马书1:3
- **从埃及被召出**: 何西阿书11:1 → 马太福音2:14-15
- **有先驱开路**: 以赛亚书40:3；玛拉基书3:1 → 马太福音3:1-3；马可福音1:2-4

## 传道事工

- **被圣灵恩膏**: 以赛亚书61:1-2 → 路加福音4:18-21
- **在加利利传道**: 以赛亚书9:1-2 → 马太福音4:13-16
- **像摩西一样的先知**: 申命记18:15-19 → 使徒行传3:22-23；约翰福音6:14
- **用比喻教训人**: 诗篇78:2 → 马太福音13:34-35
- **医治瞎眼的、耳聋的、瘸腿的**: 以赛亚书35:5-6 → 马太福音11:4-6；约翰福音9:1-7
- **骑驴进入耶路撒冷**: 撒迦利亚书9:9 → 马太福音21:1-9；约翰福音12:14-16
- **成为绊脚石**: 以赛亚书8:14；诗篇118:22 → 罗马书9:32-33；彼得前书2:6-8

## 背叛与审判

- **被朋友出卖**: 诗篇41:9 → 约翰福音13:18-21
- **被卖三十块银子**: 撒迦利亚书11:12-13 → 马太福音26:14-16；27:3-10
- **在控告者面前沉默**: 以赛亚书53:7 → 马太福音27:12-14；马可福音14:60-61
- **被门徒离弃**: 撒迦利亚书13:7 → 马太福音26:31, 56
- **被假见证人控告**: 诗篇35:11 → 马太福音26:59-61

## 受难与钉十字架

- **手脚被扎**: 诗篇22:16 → 约翰福音20:25-27；路加福音24:39-40
- **与罪犯同钉十字架**: 以赛亚书53:12 → 马可福音15:27-28；路加福音23:33
- **被嘲弄和讥诮**: 诗篇22:7-8 → 马太福音27:39-44；路加福音23:35
- **被给醋喝**: 诗篇69:21 → 马太福音27:34, 48；约翰福音19:28-30
- **衣服被分，拈阄分赃**: 诗篇22:18 → 约翰福音19:23-24
- **骨头一根也不折断**: 诗篇34:20；出埃及记12:46 → 约翰福音19:33-36
- **肋旁被扎**: 撒迦利亚书12:10 → 约翰福音19:34, 37
- **遍地黑暗**: 阿摩司书8:9 → 马太福音27:45
- **“我的神，我的神，为什么离弃我？”**: 诗篇22:1 → 马太福音27:46

## 死亡与埋葬

- **作为代替性的赎罪祭而死**: 以赛亚书53:4-6, 10-12 → 罗马书5:6-8；哥林多后书5:21
- **葬在财主的坟墓里**: 以赛亚书53:9 → 马太福音27:57-60

## 复活与升高

- **不被撇在阴间**: 诗篇16:10 → 使徒行传2:27-31；13:35-37
- **从死里复活**: 诗篇16:10；以赛亚书53:10-11 → 马太福音28:5-6；使徒行传2:32
- **升到神的右边**: 诗篇110:1 → 使徒行传2:33-35；希伯来书1:3
- **照麦基洗德的等次永远为祭司**: 诗篇110:4 → 希伯来书5:5-6；6:20；7:17

## 受苦的仆人: 以赛亚书53章

以赛亚书53章是最详尽的弥赛亚预言。写于钉十字架约700年前，它描述了：
- 一个被藐视、被人厌弃的人（以赛亚书 53:3）→ 约翰福音1:10-11
- 担当我们的忧患、背负我们的痛苦（以赛亚书 53:4）→ 马太福音8:17
- 因我们的过犯受伤（以赛亚书 53:5）→ 罗马书4:25
- 像羊羔被牵到宰杀之地，默然无声（以赛亚书 53:7）→ 使徒行传8:32-35
- 与恶人同葬，与财主同墓（以赛亚书 53:9）→ 马太福音27:38, 57-60
- 他必看见后裔，并且延长年日（以赛亚书 53:10）→ 复活

---

每一条预言都指向拿撒勒人耶稣。一个人仅凭偶然应验其中八条预言的数学概率已被计算为10^17分之一（彼得·斯通纳，*Science Speaks*）。祂应验了全部。
