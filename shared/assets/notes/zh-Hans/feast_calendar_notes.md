# 圣经节期与两种古代历法

神在利未记23章中命定了七个节期，每一个都与以色列的农业周期相关联，每一个都预指弥赛亚的工作。这些不是可选的传统: 它们是"指定的时间"（希伯来语：*moadim*），是神的历法上所设定的神圣约会（利未记23:2）。

## 第二圣殿时期的两种历法

到耶稣的时代，犹太民中通行着两种历法系统：

### 希伯来阴阳历
这是圣殿祭司体系和主流犹太教从古至今所使用的历法。它以月亮计算月份（新月 = 新的一月），并在十九年中加入七个闰月（默冬周期），以保持与太阳季节的一致。月份的天数在29天和30天之间交替。由于必须目视确认新月，月份的确切开始可能有一天的不确定性: 这就是为什么吹角节（提斯利月1日）传统上要守两天，也是为什么**"那日子，那时辰，没有人知道"**（马太福音24:36）是这个节期的一个广为人知的惯用语。第一世纪的犹太听众会立刻辨认出来，就如同中文里"八九不离十"这样的俗语一般自然。

### 艾赛尼太阳历（364天）
在死海古卷中发现（特别是《禧年书》和《以诺一书》），这种历法恰好计算364天: 52个完整的星期。每个节期每年都落在一周中的同一天。一年从星期三开始（创造的第四天，光体被造之时: 创世记1:14-19）。安妮·乔贝尔等学者提出，耶稣在最后的逾越节遵循了这种历法，这将把最后的晚餐定在周二晚上: 解决了福音书之间的表面矛盾：对观福音（说耶稣吃了逾越节的筵席）与约翰福音（说钉十字架发生在圣殿逾越节之前）。如果耶稣使用了艾赛尼历法而圣殿使用了阴阳历法，那么两种记载都是准确的：耶稣在艾赛尼历尼散月14日（周二）守逾越节，而圣殿的逾越节则在阴阳历尼散月14日（周五）。

## 七个节期

### 春季节期: 在第一次降临中已应验
- **逾越节**（尼散月14日）: 羔羊被杀。耶稣在逾越节被钉十字架（哥林多前书5:7；约翰福音19:14）。
- **除酵节**（尼散月15-21日）: 酵（罪）被除去。耶稣无罪且被埋葬（彼得前书2:22；哥林多前书5:8）。
- **初熟节**（尼散月16日）: 初熟的庄稼捆在耶和华面前摇一摇。耶稣从死里复活，成为"睡了之人初熟的果子"（哥林多前书15:20）。
- **五旬节 / 七七节**（西弯月6日）: 初熟节后五十天。圣灵在这一天浇灌下来（使徒行传2:1-4）。律法也在同一日期在西奈山颁布（出埃及记19:1）。

### 秋季节期: 等候在第二次降临中应验
- **吹角节 / 约姆·特鲁阿**（提斯利月1日）: 号角吹响。预指基督的再来："因为主必亲自从天降临，有呼叫的声音和天使长的声音，又有神的号吹响"（帖撒罗尼迦前书4:16）。这就是"那日子、那时辰没有人知道"的那个节期。
- **赎罪日 / 约姆·基普尔**（提斯利月10日）: 大祭司进入至圣所。预指以色列全国的悔改和最终的赎罪："以色列全家都要得救"（罗马书11:26-27；撒迦利亚书12:10）。
- **住棚节 / 苏克棚**（提斯利月15-21日）: 神与祂的百姓同住在棚中。预指弥赛亚的国度："看哪，神的帐幕在人间。祂要与人同住"（启示录21:3；撒迦利亚书14:16-19）。

## 其他被命令的遵守

并非每一次神圣约定都能放入月历格中。托拉还命令了四项遵守，但它们要么太频繁，要么太稀少，要么以年而非日来计量时间：

- **每周安息日**（利未记 23:3）：在年度节期之前最先列出的定时；每周从星期五日落到星期六日落守之。
- **新月 / 月朔**（民数记 10:10; 28:11–15）：每月起始的献祭与吹角；标示神对时间本身的主权。
- **安息年 / 施米塔**（利未记 25:1–7）：每第七年土地安息；不耕种、不修剪，债务得免（申命记 15:1–2）。
- **禧年 / 约贝尔**（利未记 25:8–12）：经过七个安息年的循环后，在第五十年吹响羊角宣告；奴仆得释放，祖业归还原家。此模式预指基督，主在路加福音 4:18–19 宣告"主悦纳人的禧年"（引以赛亚 61:1–2）。

这些超出每月格子的范围，但仍是完整圣经历法的一部分。

## 创世记1:14

"神说：'天上要有光体，可以分昼夜，作**记号**，定**节令**（*moadim*: 指定的时间），日子，年岁。'"天体的创造，部分目的就是标记神的节期历法。
