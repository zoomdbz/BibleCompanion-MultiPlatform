# Carte des Prophéties Messianiques

Les Écritures Hébraïques contiennent plus de 300 prophéties pointant vers le Messie. Ci-dessous figurent les principales avec leur source dans l'Ancien Testament et leur accomplissement dans le Nouveau Testament. Chaque référence est exacte; lisez-les vous-même.

---

## Naissance et Origine

- **Né d'une vierge** : Ésaïe 7:14 → Matthieu 1:22–23
- **Né à Bethléem** : Michée 5:2 → Matthieu 2:1–6
- **De la tribu de Juda** : Genèse 49:10 → Matthieu 1:2–3 ; Hébreux 7:14
- **De la lignée de David** : 2 Samuel 7:12–13 ; Ésaïe 11:1 → Matthieu 1:1 ; Romains 1:3
- **Appelé hors d'Égypte** : Osée 11:1 → Matthieu 2:14–15
- **Précédé par un messager** : Ésaïe 40:3 ; Malachie 3:1 → Matthieu 3:1–3 ; Marc 1:2–4

## Ministère

- **Oint par l'Esprit** : Ésaïe 61:1–2 → Luc 4:18–21
- **Ministère en Galilée** : Ésaïe 9:1–2 → Matthieu 4:13–16
- **Un prophète comme Moïse** : Deutéronome 18:15–19 → Actes 3:22–23 ; Jean 6:14
- **Enseignement en paraboles** : Psaume 78:2 → Matthieu 13:34–35
- **Guérison des aveugles, sourds et boiteux** : Ésaïe 35:5–6 → Matthieu 11:4–6 ; Jean 9:1–7
- **Entrée à Jérusalem sur un âne** : Zacharie 9:9 → Matthieu 21:1–9 ; Jean 12:14–16
- **Pierre d'achoppement** : Ésaïe 8:14 ; Psaume 118:22 → Romains 9:32–33 ; 1 Pierre 2:6–8

## Trahison et Procès

- **Trahi par un ami** : Psaume 41:9 → Jean 13:18–21
- **Vendu pour trente pièces d'argent** : Zacharie 11:12–13 → Matthieu 26:14–16 ; 27:3–10
- **Silencieux devant ses accusateurs** : Ésaïe 53:7 → Matthieu 27:12–14 ; Marc 14:60–61
- **Abandonné par ses disciples** : Zacharie 13:7 → Matthieu 26:31, 56
- **Accusé par de faux témoins** : Psaume 35:11 → Matthieu 26:59–61

## Souffrance et Crucifixion

- **Mains et pieds percés** : Psaume 22:16 → Jean 20:25–27 ; Luc 24:39–40
- **Crucifié avec des malfaiteurs** : Ésaïe 53:12 → Marc 15:27–28 ; Luc 23:33
- **Moqué et ridiculisé** : Psaume 22:7–8 → Matthieu 27:39–44 ; Luc 23:35
- **On lui donna du vinaigre à boire** : Psaume 69:21 → Matthieu 27:34, 48 ; Jean 19:28–30
- **Vêtements partagés, sort jeté** : Psaume 22:18 → Jean 19:23–24
- **Aucun os brisé** : Psaume 34:20 ; Exode 12:46 → Jean 19:33–36
- **Côté percé** : Zacharie 12:10 → Jean 19:34, 37
- **Ténèbres sur la terre** : Amos 8:9 → Matthieu 27:45
- **"Mon Dieu, mon Dieu, pourquoi m'as-tu abandonné ?"** : Psaume 22:1 → Matthieu 27:46

## Mort et Sépulture

- **Mort comme sacrifice substitutif** : Ésaïe 53:4–6, 10–12 → Romains 5:6–8 ; 2 Corinthiens 5:21
- **Enseveli dans le tombeau d'un riche** : Ésaïe 53:9 → Matthieu 27:57–60

## Résurrection et Exaltation

- **Non abandonné au séjour des morts** : Psaume 16:10 → Actes 2:27–31 ; 13:35–37
- **Ressuscité des morts** : Psaume 16:10 ; Ésaïe 53:10–11 → Matthieu 28:5–6 ; Actes 2:32
- **Monté à la droite de Dieu** : Psaume 110:1 → Actes 2:33–35 ; Hébreux 1:3
- **Prêtre pour toujours selon l'ordre de Melchisédek** : Psaume 110:4 → Hébreux 5:5–6 ; 6:20 ; 7:17

## Le Serviteur Souffrant : Ésaïe 53

Ésaïe 53 est la prophétie messianique la plus détaillée. Écrite environ 700 ans avant la crucifixion, elle décrit :
- Un homme méprisé et rejeté (Ésaïe 53:3) → Jean 1:10–11
- Portant nos douleurs et nos souffrances (Ésaïe 53:4) → Matthieu 8:17
- Blessé pour nos transgressions (Ésaïe 53:5) → Romains 4:25
- Comme un agneau mené à l'abattoir, en silence (Ésaïe 53:7) → Actes 8:32–35
- Sa sépulture avec les méchants, son tombeau avec le riche (Ésaïe 53:9) → Matthieu 27:38, 57–60
- Il verra sa postérité et prolongera ses jours (Ésaïe 53:10) → Résurrection

---

Chaque prophétie pointe vers Jésus de Nazareth. La probabilité mathématique qu'une seule personne accomplisse ne serait-ce que huit de ces prophéties par hasard a été calculée à 1 sur 10^17 (Peter Stoner, *Science Speaks*). Il les a toutes accomplies.
